# 2足球框架 V17.4.99 · 情报优先执行器（瘦身版）

**足球分析的乐趣与正确顺序在情报与球队，不在赔率算术。** 低赔（1.3/1.4）≠稳；方向、排除、倾向、锁\*、「稳腿」**只许用情报**定，竞彩 SP / 亚欧赔率禁止单独或主导定方向（第三节）。
**正文只写当前有效规则**；每条规则哪天谁点名、依据哪场、哪些已作废 → `references/版本史.md`（V17.4.67～4.99）。
**准度北极星**：本 skill 专注比赛分析准确率——**推的准确率只算倾向≠不定的单选**（V17.4.99）；观望 / 强制=不定不进这个分母。赛前冻结与赛后评估按 `references/票面校验.md`；命中率、概率校准、实际净收益分开统计，不以 lint 全绿证明准度或盈利。研究日看这一格的命中 + 比分命中（有装箱时）；下注单日另加 **票中**。主不败宽网、硬装出来的单选，都不能叫推得准。交卷二分、空仓、弱置信、质量层、lint 绿，都是为**抬准或防假准**服务；禁止把「流程绿 / 空仓成立」当准度。改条款前自问：会让命中更好，还是只让稿子更好看？后者不动刀。

**冻结（2026-10-23 起，到账本满 30 场）**：只修明显错误（规则自相矛盾、lint 误报漏报）；新发现一律记 03 的 Shadow，满 30 场一起复查再提案。亲爱的点名改纪律除外。
**改 skill 门槛**：单夜 miss 只记 Shadow，不改条款；同类 miss ≥2 夜（或结构性口径错）才提案；只改源仓 `AQQ/football-predict-v17/`，改后 `bash scripts/sync-skill-bundle.sh`。冲突序：本 skill > 主控 > 人设 > 插件。

## 作业流（强制顺序）

0. 多场先读 `防偷懒.md`；文首点名 `交卷模式=`。
0b. **（V17.4.71 · 下注单）先选场**：全表每场 ≤3 行粗筛 → 写 **【票面候选】**（≤4 编号 + 剔因；稳+博双票日≤4，研究板/单票日优先≤3）→ **认真拆集合=候选**（可写 `认真拆=票面候选`）。研究板可写 `【票面候选】无｜研究板`。
1. **只对候选取证（V17.4.78 接口优先）→【取证清单】**：① 直接请求 `analysisJs/data{id}.js` + `detail/{id}cn.html` 落盘 `_raw/`（近况/积分/交锋/技统）；② **ego** 抄列表「荐」后 SPF/让球（三格须为数字）+ 缺阵对账；③ 需要时三合一/胜平负；④ **必开**教练/裁判/捷报猫（V17.4.86；落 `_raw/style/`，01a `【三页取证】`；猫只摘事实）。**不开 sporttery、不开雷速**；认真拆亮【认真拆必采】+【主菜质量层】。非候选只写观察骨架。
1b. **（V17.4.72）写 `01a-认真拆-NNN.md`**：每候选必含【近况比分表】【赛程前后】【排除因果】【反剧本因果】；01 同场节末链 `过程=`。
2. 【情报叙事】→【球队画像】→【比赛剧本】：排除（可暂缓）→ 剩余 → 二次 → 方向 → 倾向 → 净胜档 → 比分（按交卷模式）→ 进球。可先看结构盘；钉向后写【方向冻结】。过程展开优先写进 01a，01 保留结论槽供 lint。
3. 过【专闸触发表】；命中则按详表动作改方向/星级/TOP。
4. 扫盘：`初盘=真开盘|竞彩现盘|缺` + 现 SP/让球；认真拆且可介入才跑 λ/Edge/V15.6。
5. 出票闸 → 【研究推荐】/【出票】/【投注星级】→ 文末【全场汇总表】+【今日票面】（下注单另加 TOP / 让球稳健）。**票腿编号必须 ⊆【票面候选】**。
6. 交卷前跑 `python3 scripts/lint_draft.py <01>`（稿日自动取路径日期，可 `--day` 覆盖）；未过 lint 不得宣称完成。候选证据再跑 `audit_delivery.py evidence`，非空仓再跑 `audit_delivery.py ticket`；结构化清单格式见 `references/票面校验.md`。在 01 文末写 `证据审计=通过|未验证|失败|未触发｜票面算术=通过|未验证|失败|未触发｜赛前冻结=完成|未验证`，仅依据实际调用结果填写；空仓写 `票面算术=未触发`。`python3 scripts/check_day.py <日夹>` 汇总 01 lint、03 分母与伴随审计状态；缺失不得冒充通过。缺清单或未通过时须写未验证，不得以 `翻倍=过` 字样冒充计算或取证已核。

**必出**：【取证清单】【情报叙事】【球队画像】【比赛剧本】（命中焊标签时含【反剧本收据】）【硬闸自检】（出票通道+降维+V15.6）【结果预测】【研究推荐】【出票】【投注星级】【全场汇总表】（多场日）；候选另必出对应 `01a`。格式见 `output-template.md` + `01a-认真拆模板.md`。

## 一、交卷模式与分诊

| 模式 | 第一读者问题 | 主交卷 | 票面 | 方向 |
|------|--------------|--------|------|------|
| **研究板** | 方向/比分/扫盘怎么看？ | 【全场汇总表】+ 扫盘 | 仍必有；**空仓默认合格**（写弃因） | 可 `观望/不定罩` 或 `不败｜弱置信=是` |
| **下注单** | 今天小票买什么 / 为何空仓？ | 【今日票面】可买腿或如实空仓 | **有票才统计票中；空仓只记执行状态** | 有一侧写锁\*/不败；无一侧可观望，观望禁充腿 |

```text
交卷模式=研究板｜或｜下注单
```
亲爱的未点名：说「给分/扫盘/不推票」→ 研究板；说「最少二串一/推票」→ 下注单。复盘「调中了没」：下注单=票中；研究板空仓日=方向仓+比分仓，空仓不算 FAIL。

**全表分诊**（禁止 N 场同等长文；**下注单硬序=先候选后深挖**）：

| 池 | 上限 | 篇幅 |
|----|------|------|
| 粗筛（选场） | 全表 | 每场 ≤3 行：能否锁\*/让侧、伤停硬词有无、是否薄客不败；写出进/剔 |
| 【票面候选】 | **≤4** | 文首必亮编号列表 + `剔=`；无合格场写 `无｜弃因=` |
| 重点认真拆 | **=候选**（≤4） | 01：取证摘要+必采+质量层+叙事+画像+情景+扫盘+冷门预防+方向冻结（+λ校准）+`过程=01a-…`；**过程加厚写 01a**（比分表/赛程/排除·反剧本因果） |
| 观察骨架 | 非候选 | ≤6 行/场；**禁止**事后升进票面（除非改候选并补认真拆）；**不写 01a** |
| 票面池 | 0～若干腿 | **腿 ⊆ 候选**；研究板可空；真下才临场核 XI |

认真拆 >4 须砍或写明破例（亲爱的点名）。认真拆 ≠ 候选 → lint ERROR（V17.4.71）。

```text
【票面候选】≤3｜005｜015｜020｜剔=其余观望/只能不败无让侧/伤停槽弱
分诊：认真拆=票面候选
```

**粗筛过闸（进候选）**：按赛前情报、对位、战意与可检验的剧本优先筛，须有可深入验证的一侧或让侧线索；伤停/战意未核可列待证，禁止用低赔或往昔一场失利代替全场对位。**候选是分析集合，不是出票集合**：胜平负未开售、某玩法翻倍不过或凑不成二串，只能在后续出票闸淘汰该腿，不能单独作为剔除分析候选的理由。候选无合格证据也可为空，写清情报弃因。进候选后照写 **【市场漏】**（只记账，不作剔因）。

**候选分级（V17.4.100 · AI 好读）**：每个候选写一行，分三级。票腿只用 ★★★ 和 ★★★★；★★ 仅研究不进票。

| 级 | 含义 | 进票 |
|----|------|------|
| ★★★★ | 情报强+剧本清晰+可锁 | 稳/博均可 |
| ★★★ | 情报够但有明显弱点/弱置信 | 稳须谨慎，博可用 |
| ★★ | 有倾向但证据不足 | 不进票 |

```text
候选评级：
002 ★★★★ 锁主｜主6连胜失1球，客近6仅1胜｜可进稳
011 ★★★★ 锁主｜客0胜失14球三连败｜可进稳
010 ★★★★ 锁主｜客中锋新缺+层级低｜可进稳
001 ★★ 观望｜主攻击线缺5人+半场弱｜不进票
```

共胆规则：默认稳博禁共用胆。亲爱的点名「可以用共胆」时，票面须写 `共胆=点名放行` 并说明风险；**共胆仅限胆为锁\*且非低结构场（draw_priority）**，低结构场禁当共胆（V17.4.101）。

```text
【市场漏】押=锁主｜隐含=66%｜我估=74%｜漏=客双后腰停赛开盘后才出，主胜SP未动
```
**【市场漏】只记账、不挡票**（V17.4.83）：没漏不代表不进票、【市场漏】看不到不代表票腿不合格；票腿是否进票由情报独立成立与否+翻倍核算决定，`我估-隐含` 仅用于复盘核对模型，不能作为当日是否出票的理由。

**票面候选升档（V17.4.67，被 4.71 收紧）**：拟进票场 **必须已在【票面候选】且已认真拆**。`分诊弃锁=` 只允许标「曾想进票但未升」的弃因，**禁止**用弃锁把骨架场写进稳/博腿。

## 二、取证与情报

### 自研纪律（硬）

方向与票面只由本框架自研；第三方「结论产品」不进证据链。
- **禁**：荐单/计划单/连红专家/高手推荐/站点 AI/雷速荐单/聊天室/自媒体；口头禁报「某专家也看这方向」；`SOURCE_URL` 禁写荐单页。**不禁**打开教练分析·裁判分析·捷报猫采**事实/风格/尺度**；禁把其页内「看好/推荐方向」焊锁\*。
- **捷报（V17.4.78 唯一取证源 · 接口优先）**：主菜直接请求 `live.nowscore.com/analysisJs/data{id}.js`（近况 `h_data`/`a_data`·积分·H2H）+ `detail/{id}cn.html`（技统·进失球概率·走势），**落盘 `_raw/`**；列表 SPF/让球用 **ego** 渲染抄格；缺阵以数据分析 HTML 为准。需要时三合一/胜平负。**三页（候选必开·ego · V17.4.86）**：教练分析·裁判分析·捷报猫（猫=AI 生成，只摘事实标已核/待证）。REA 仅兜底。标题队名对不上 → 重进。
- **雷速 / 体彩官网**：认真拆**均不再必采**；禁 `SOURCE=体彩|雷速` 或开 sporttery/leisu 凑页。
- 通道：结构化主菜=直接请求；列表 SPF 与交互辅扫=ego；细则见 `references/取证速查.md`。禁「网页一律只开浏览器、不落盘」。

### 【认真拆必采】（认真拆必写 · 取证后排除前 · 缺行 lint WARN）

```text
【认真拆必采】伤停=有源|未见|槽弱｜机会代理=<技统进失/被射/角球一句|已查捷报无xG>｜初盘=真开盘|竞彩现盘|缺
```
未打开捷报现场分析禁写 `未见`；初盘词须与扫盘/即时走势同词。

### 情报档 · 伤停未知封顶

```text
情报档=充足|偏薄|不足｜动作=PROCEED|CAUTION|STOP｜伤停=有源|未知｜一句≤15字
```
- **伤停 `已核` 只认本场来源**：本场缺阵名单、赛前官方/主帅发布会、开赛前正式首发；「上一场没首发」「近期出场」只能 `待证`；detail「预计首发」与缺阵名单打架 → 两边都写、标 `待证`（细则 `references/取证速查.md`「已核口径」）。
- 伤停未知/未见/槽弱 → 最高 **偏薄/CAUTION**；禁 PROCEED；研究星封顶 ★★★☆☆；不进票面 TOP1。
- **偏薄不是结案章（V17.4.67）**：拟锁\*或拟进票 → **先补采**（捷报 MatchDetail 全序，尤其现场分析）再二次；补采后仍薄 → 写 `情报档=偏薄｜补采=已做｜仍不锁=…`，并须写明偏薄的具体槽（伤停无源/xG缺/令页未开），不得用「偏薄」搪塞。骨架分诊停写可以，须标分诊，禁用两年旧 H2H/「刚负强队」单独挡锁。
- **观望成本**：观望 ≠ 躺平。写观望的场要求同一屏句面可推的备选方向（如「倾向=主胜但可观望」、「差一步到锁」）；「没有一侧」的观望场不能仅写「无一侧」，须写明是双方均无明显强项还是互不克制。同一天观望场次>6/14，写【整体观望原因：是情报普遍薄还是今日盘子特殊】。
- **不足** → 停深度叙事、不进 TOP；但有初盘类型+现盘仍须交方向（可走深让 A）；禁「不足=自动放弃方向」。
- 禁写假精确 ICS 分（旧稿 `ICS≈70` 仍认）。红旗措辞（"绝对""复仇必胜"等）lint 会扫，触发须重写段落（清单见详表）。

## 三、剧本：排除 → 方向 → 倾向

### 情报定方向硬闸（V17.4.69 · 亲爱的点名）

**定什么只许看情报**：`排除` / `剩余` / `二次` / 方向原子（锁\*·不败） / `单子倾向` / 聊天与【今日票面】里的「稳腿」。硬情报＝伤停、轮换、状态、战意、连败、克制、板凳、赛程负荷、交锋正式样本等（同排除三件套①）。

**赔率 / SP 允许干什么（白名单，禁越权）**：
| 用途 | 可以 | 不可以 |
|------|------|--------|
| 专闸触发阈值 | 低结构贴脸、深让 SP≤1.35、深盘陷阱 SP 阈值 | 用阈值本身当排除理由或锁\*依据 |
| 盘口质疑辅证 | 亚盘异动/背离写进 `质疑=`，削弱锁热侧 | 无①硬情报时单靠质疑排胜负边定方向 |
| 出票算术 | Edge、串关到手、过 N 倍赔付 | 「赔率低所以稳」「SP 热所以锁」 |
| 复盘账本 | 买热门基准、Brier、隐含概率对照 | 用热门命中率倒逼改下一场方向 |

**硬禁**（口头/稿内同罪）：
1. 「SP≤1.50 / 1.3 / 1.4 所以稳」「热门低赔当胆」。
2. 排除行或二次行用「主胜 SP 低/客胜贵/赔率支持」当主因。
3. 【深让可锁】`依据=` 只写盘口/水位、无硬情报词 → 视为无 A 收据（须走 B 降维或不锁）。
4. 聊天给票把「稳」写成低赔串；要过 2 倍须明说「提高赔付≠提高命中」，腿仍须情报 PROCEED。

### 排除三件套（硬）

| 层 | 看什么 | 作用 |
|----|--------|------|
| ① 情报（硬） | 伤停、轮换、状态评分、战意、连败、克制、板凳深度 | **唯一决定**谁最不可能；定排除/方向 |
| ② 盘口/水位（质疑） | 亚盘深浅、初终异动、竞彩↔亚盘背离 | 辅证：可把名气低赔打成「假热」**削弱锁热侧**；不得单独定方向 |
| ③ 竞彩 SP（参考） | 谁贵谁冷 | 只定买热门基准与闸门阈值；**禁单独、禁主导**决定排除/方向/稳 |

```text
排除=<主胜|平|客胜|暂缓>｜理由=<硬情报≤15字>｜质疑=<盘口≤10字|无>
剩余={…}｜二次=倾斜…→锁* 或 分不清→不败｜单子腿=
```
1. 排胜负边：`理由=` 须含硬情报词；`质疑=` 只作辅证。禁仅用主场优势/经验/名气/纸面实力等软词。无硬词 → lint ERROR（**日夹 ≥2026-10-12**：有质疑无硬词仍 ERROR，V17.4.69）。
2. SP 低/名气大不免死；排假热须①硬情报成立，②质疑只削弱锁\*、不单独排边。
3. **反向对位硬闸**（V17.4.101 · 亲爱的点名）：排主胜/客胜成立时（被排方防守崩/进攻瘫痪/伤停核心新缺），不得因「主队主场有平有负/最近一场输/主场不是连胜」单独观望。须先完成【强弱对位】并判断对方是否比主队更差；对方更差→按规则锁；对方不比主队更差→可暂缓或观望。
4. **假热闸**：`质疑=假热` 只削弱热侧锁\*，禁据此排**冷侧**（除非另有硬情报词）→ lint ERROR。
4. `排除=平` 可贴脸/闷平，仍禁空理由；禁靠扩大「不定/观望」刷排除仓。
5. **暂缓**：仅当 `情报档=偏薄|不足` 或揭幕首秀或关键槽<2；理由写 `情报档偏薄|不足|揭幕|槽不足`（禁写「ICS低」）；暂缓后禁用软词补砍充排除仓；有硬情报后补砍并写修订。汇总表排除列写 `暂缓`。
6. **逆热门排除旁注（观察计数 · 未满进化闸账本 30 前不升硬闸）**：若排除的是胜平负 SP 最低一侧，理由旁加 `逆热门排除`（方便复盘计数）；方向仍须①硬情报自洽，禁用「逆热门」本身当理由。
7. **伤停排除（V17.4.92/93）**：理由靠伤停/缺阵/资格限制排主胜|客胜 → 须写 `【伤停排除】核心缺=<哪个核心位置/人>｜打不了=<被排方因此具体做不到什么>｜缺几场=新缺`；只有「名单长/伤停重」写不出 → **只能暂缓**。`缺几场` 看缺阵页「上一场阵容」：核心在上一场阵容=新缺，不在=已缺（影响已在近况里）；欧战资格限制=旧缺。**已缺/待证 → 伤停不能当排除理由**，近况差就改写近况理由，近况不差就暂缓。lint ERROR。
8. **强弱对位**：认真拆 `排除=主胜|客胜` 前必写 `【强弱对位】被排方强项=…｜对方弱项=…｜打得到=否|是`；被排方强项打得到对方弱项（含对方虚高防守/被射多失球少）→ **禁排该边**，改暂缓或换侧；禁拿对方弱点去配我方本就弱的单元。排主胜另加 `主场=挡得住|挡不住`，`挡不住` → 禁排主胜；写主场评价须同屏给依据（如「主场近2挡得住中游但挡不住上强」或「主场防守档=1.2失球，对方进攻代理=1.8进球」）。lint ERROR。
9. **倾斜可锁但允许降级**：`二次=倾斜主胜/客胜/平` 可锁；但强弱对位打得到=是或主队主场=挡不住时，可退写成不败并写【深让降维】理由（从√改为同场「非顺利」原因）。

### 方向原子

| 模式 | 允许 |
|------|------|
| 下注单 | 有一侧：`锁主/锁客/锁平/主不败/客不败`（单选可写主胜/客胜/平局=锁）。没有一侧：`方向=观望`（二次=分不清；倾向=不定；须 `理由=` 或 `弃因=`） |
| 研究板 | 上列；或 `方向=不定罩`（仍给进球+扫盘）；或 `主不败|客不败｜弱置信=是` 且倾向有一侧 |

- 允许集：锁主={主胜}；锁客={客胜}；锁平={平}；主不败={主胜,平}；客不败={客胜,平}；观望=∅（不计方向 miss，也不进推的准确率）。
- **禁胶着、禁空槽、禁方向空着。** 观望 ≠ 胶着（观望是显式 pass，不进票面腿；汇总表写 `观望`、倾向 `不定`、强制 `不定`）。有倾向的场禁止改写成观望。
- 回话表只列倾向≠不定的场，一行一个结果（倾向那一格）。观望场写不推。
- 研究板偏薄/伤停未知：默认暂缓排除 + 观望/弱置信不败；禁硬砍冷侧充排除仓。
- **锁平许可证**：须含 0-0 或 `闷平/TRUE_00/死盒/焊平` 句面；犹豫不是平。

### 单子倾向

因果硬：**允许集 → 倾向 → 再装箱**；禁用主推比分 1X2 倒推倾向。
- 倾向 ∈ 允许集（主不败禁倾向客胜；客不败禁倾向主胜）；分不清写 `不定`。
- 锁\*场汇总表倾向列必填所锁格。
- `02` 先写方向行，下一句才写单子腿；禁把倾向写成锁主/锁客/锁平。

### 二次确认（方向原子前必过）

认真拆场（及票面候选升档场）在定方向原子前须写一行：`二次=分不清｜排除后仍平` / `二次=倾斜主胜｜…` / `二次=倾斜客胜｜…` / `二次=倾斜平｜…`。禁跳过；禁用「ICSxxx」代替。

- **二次=倾斜主胜/客胜/平** → 可锁；强弱对位打得到=是或主场=挡不住时可退写成不败并写【深让降维】理由。
- **二次=分不清** → 不败即可；可写 `权重印象=主>平≫客`（定性，非假精确 %）。
- 假热可挡锁\*，**不得**把二次从倾斜改成「假热所以不定倾向」。

## 四、比分与进球

**硬序（禁颠倒）**：方向 → 倾向 → 净胜档（闷平/小胜/中胜/大胜）→ 有把握才主/次/防 → 进球区间由主+次总球反推（无比分时进球仍必出）。比分是情景装箱，不是 SP 公式吐分。观望也必须交付可核的进球区间/档（数据不足时标弱置信与弃因，不得写 `进球=不定` 当作已交付）；进行中/完赛或未纳入赛前预测的场须单列跳过原因，不能冒充赛前预测。

| 格 | 装什么 |
|----|--------|
| 主 | 最像终场；∈允许集；有优势须胜负球（禁用 1-1 当锁向安全垫） |
| 次 | 同族次高频；倾向已定则主次同族 |
| 防 | 倾向已定 → 允许集另一向（不败常防平）；不定 → 权重 Top3 且须含平；收据过闸可挂 ±1 反方向 |

| 交卷模式 | 比分 |
|----------|------|
| 研究板 + 情报充足且伤停有源 | 默认给主/次/防（没把握仍可弃权） |
| 研究板 + 伤停未知/偏薄/不足 | 默认弃权；点名「要好看」才装箱并写 `弱置信=是`（揭幕闸场不可绕过） |
| 下注单 | 默认弃权；仅认真拆过闸（λ有 / 情报充足且伤停非未知 / 亲爱的点名）才装箱 |

- 禁小胜垄断三格；**深盘碾压**（让球≥2 或对手近 5 失球≥10/防线残≥3）→ 防或旁至少一格屠杀分（3-0/4-0/5-0/4-1 或客侧对称）。
- 三桶补偿、结构档、HT/FT 分轨、剧本 13 条细则见详表。
- **λ 校准**（有可靠 λ 时）：先列 4～5 个合法候选 → λ 重排 → 极冷格不进主/次 → 进球档优先吃 λ；禁全表泊松 Top1 焊主格；禁 λ 倒推方向；无可靠 λ 不硬泊松。

  ```text
  λ校准=有｜λ′_H=·｜λ′_A=·｜主次按池序=·/·｜否证掉=·或无   （无则 λ校准=无｜理由=·）
  ```

## 五、佐料（初盘诚实）与出票闸

| 初盘类型（扫盘行必选一） | 水位怎么写 |
|--------------------------|------------|
| `初盘=真开盘` | 初→现路径可写撤热/灌热/背离 |
| `初盘=竞彩现盘` | 只写「竞彩现盘对照」；禁假装亚欧开盘路径 |
| `初盘=缺` | 水位写 `缺`；禁可介入；研究板仍可给方向 |

1. 禁只凭即时 SP 或孤立 Edge 定可介入；Edge 必须与初盘锚+水位+现 SP/让球同屏。
2. 竞彩支持率=民意辅证，不得单独焊锁\*或定排除。
3. 佐料默认不改方向；**否证回流**（水位/现盘相对已冻方向剧烈背离、λ′ 严重打架、临场伤停爆出）→ 回流重判并写 `对照盘口修订=`。
4. 双闸门（仅出票）：胜平负 Edge_eff ≥1%；让球/进球 ≥3%（≥5% 可标高赔单关主推）。Edge_Refine/MKT_CONFLICT 只改【出票】提示。降维方向与结果预测打架 → 出票观望。
5. V15.6 五补丁仅认真拆且出票可介入场扫（其余写 `触发=跳过｜池=观察`）；命中 Zombie 须写「⚠️ 深盘陷阱预警」。
6. **Edge 诚实**：体彩抽水厚，多数场 Edge 为负属正常 → 出票观望，但仍交方向+进球（比分有把握才交）。

**临场闸**：日间 XI 拿不到 → 票空仓/纯研究**免写**。仅真下或 T-60/T-30 复核才写 `【临场闸】XI=已确认|未确认｜时点=｜动作=保留|撤腿|降观望`；未确认只能撤腿/降观望。禁写 `待临场确认`。

## 七、文末：汇总表 · 票面 · TOP · 让球稳健

| 编号 | 对阵 | 排除 | 推方向 | 倾向 | 让球胜平负 | 比分 | 进球 | 强制 |
|------|------|------|--------|------|------------|------|------|------|
| … | … | 主胜\|平\|客胜\|暂缓 | 锁\*\|主不败\|客不败\|观望 | 主胜\|平\|客胜\|不定 | 让球主胜(主-N)\|让平(主-N)\|让负(主-N)\|不定\|未开售 | a/b/c 或 比分弃权 | 区间 | 有倾向：主胜\|平\|客胜 / a/b/c；观望：不定 |

1. 行数=本篇全部编号场（完赛跳过）；缺列/锁\*倾向留空/缺让球列 → lint ERROR。

4. **强制列（V17.4.99 改 4.68 的硬装）**：有倾向的场必填 `单选/主/次/防`（如 `主胜/2-0/1-0/2-1`），单选=倾向；比分非弃权 → 三格=比分篮（同序）。比分写弃权但强制列有三格时，三格是**赛前强制账**，只能进入复盘的“强制比分三格”分母，不能进入“出手比分篮”分母；两本账不得混报。**没有一侧 → 方向=观望，强制列只写 `不定`，禁止硬装主胜/平/客胜和三格。** `不定` 不进推的准确率，不进票。有倾向的场禁止赛后改成观望。强制列只记账、不进票面。复盘按 `references/复盘条款.md`。

### 【今日票面】

资金走 `@数据/账本.md`。亲爱的另点名预算/形态从其点名。

```text
【今日票面】
预算=按注数｜形态=稳+博
稳=按注数｜A锁主*×B锁主*｜中率≈NN%｜翻倍=过（每条命中路≥2倍该票本金）
博=按注数｜C任一玩法×D任一玩法｜分注｜翻倍=过（每条命中路≥2倍该票本金）
或：稳=空｜弃因=翻倍不过|无干净腿 ／ 博=空｜弃因=翻倍不过|没边 ／ 方案=空仓｜弃因=没边|研究板
（仅非空仓且已逐路核算）账本=过｜翻倍=过｜一句=每张票每条命中路返还≥2倍该票本金；空仓写账本=未触发｜翻倍=未触发
```

**钱与张数**
1. **不设每天 12 元上限**（2026-11-03 起，4.90 的 12 元和默认 8+4 不再卡注数）。仍是一张稳 + 一张博，可空其中一张（写弃因）。金额按注数：每注 2 元，进球区间几档就几注，再乘对腿注数和倍数。翻倍按该票实际本金。**没边就空仓**（没有可结算尖腿 → `方案=空仓｜弃因=没边`）。非空仓须亮 `账本=过`，并用 `tickets.json` 逐路核对；缺数据写未验证，不得宣称已过。禁止为了压进某个金额改玩法、少买区间里的档。
2. 每张 **≥2 场**（禁单关）；串数不封顶，但每多一关多扣一层抽水（单关≈11%、二串≈21%），默认两场。单关只在亲爱的点名时：博/大博/机动 ≤4 元｜`SP≥2.0`｜`我估≥40%`，稳不放行。
3. 腿编号 **⊆【票面候选】**；腿须**跨场**（同编号两玩法禁写过关串）；该玩法须已开售；每腿写清玩法。大博/机动默认不出，亲爱的点名才写（精确比分可，不进准度 KPI）。

**玩法**：不限——胜平负/让球/进球数/半全场/比分/复式皆可，**按剧本挑最贴的**；禁默认把每腿写成全场胜平负单选凑串。复式分注每注 2 元整数倍，**每条命中路单独算**翻倍。

**稳**（求中）
1. 门槛 **`翻倍=过`**：每条命中路返还 ≥2 倍该票本金（中一次至少抵一次冷门）；写 `中率≈NN%`（SP 去水估，供复盘，不设硬线）。在过翻倍的组合里挑**最容易中**的，别往高抬（10-17 起稳要 4 倍，连黑 14 张）。例：8 元 `1.40×1.45` 1 注 4 倍 → 16.2 过；`1.30×1.35`=1.76 不过；`锁1.36×胜/平(1.90/3.45)` 分 6+2 → 15.5/9.4 不过（平路不到 16）。过不了 → `稳=空｜弃因=翻倍不过`。赔率高低不改长期亏损（抽水≈21%/二串），只改输赢节奏；能转正的只有腿比市场准。
2. 场须 `情报档=充足` 且 `PROCEED`；`CAUTION|STOP` / `弱置信=是` → 禁进稳。
3. 不败（主不败/客不败）进稳：**首选 `胜/平`（客侧 `负/平`）复式或让球玩法**（主让让球主胜+让球主胜、客让让球客胜+让球客胜）；复式或让球串每条命中路必须核算返还。禁把倾向格主胜/客胜单选塞进稳。复式过不了翻倍时可改用让球玩法进稳，但须明说 `出票通道=让球` 并写盘口。
4. **让平禁进稳**（只赢 1 球才中，≈24%）；**禁为过门槛把让平塞回稳**。
5. 让胜(主-N) 进稳 → 主推比分净胜 ≥N+1（主-2 配 2-0 不行）；让负(主+N) 进稳 → `净胜档=中胜|屠杀` 或比分篮有客净胜≥2 格。
6. 稳串第二腿（`×` 右侧）为锁客\*/客胜/让负且客 SP=三格最低（客热）→ 禁进稳。
7. 禁「赔率低所以稳」；锁\*不够两腿 → 稳降额或空，禁凑满。

**博**（求赔）
1. 门槛 **`翻倍=过`**：每条命中路返还 ≥2 倍该票本金。
2. 让平、比分、总球、半全场可作博腿，须**尖**、有赔率弹性；进球档跟剧本（闷 `1+2` / 常 `2+3` / 攻 `3+4`）；禁弱让球冒充博。
3. CAUTION/弱置信场进博 → 该腿须复式罩住【冷门预防】点名的结果，否则不进。胜/平罩不住点名的对面赢时，本条不能把腿拧成胜/平。
4. **谁赢盖不住禁止译成胜/平**（V17.4.98 · 11-02 亚特兰大 0-3）：倾向一侧、反剧本里的平、对面赢三个都还活着 → 胜平负没有可买的腿，`出票通道` 不得用胜平负。剧本另有进球区间 → `出票通道=进球`，区间内每一档都买。禁止改回胜/平，禁止只买区间里赔率最低的一档，禁止拿反侧让球补救。已经倾斜到单侧（锁\*或倾向单边，且冷门预防没有点名对面）的场仍买该侧，不改去买进球。

**分散**（全部票合计）：低结构平优先场最多出现 **1 次**；锁客\*/客胜/让负腿最多 **1 次**；稳与博**禁共用同一胆腿**（亲爱的点名共胆除外，票面须写 `共胆=点名放行`）。

**比分篮执行**：锁\* / 【深让可锁】 / 净胜档含屠杀且已装箱 → 三格至少一格净胜≥3。

**口径**：亲爱的要稳票赔率 >N 倍 → 明说「提高赔付≠提高命中」，禁为凑倍把「赢」抬成「必须净胜≥2」；深热主胜（SP≤1.50）进串须写情报翻车点；不标仓位%。


**TOP 分席**：每条标 `席=票面|观察`。票面席须写 `买=` 可结算映射，禁「不败+倾向不定」；观察席不计票面 3/3。宁缺，票面席 0～2。

## 禁止（汇总）

- 选场：先铺全表再凑票；无【票面候选】；认真拆≠候选；票腿出候选池；用 `分诊弃锁` 把骨架塞进稳/博。

- 票面：没边仍凑票；单张只有 1 场（未点名）；非空仓无 `翻倍=过` 或任一命中路 <2 倍本金；不败单选拧进稳；让平进稳；CAUTION/弱置信进稳；客热第二腿进稳；小胜档让负进稳；让胜(主-N)净胜不足 N+1；低结构/押客腿进 ≥2 张票；稳博共用胆；同场两腿过关；CAUTION 场单选进博；默认全场胜平负单选凑串；锁\*/屠杀档比分篮无净胜≥3 格。
- 先算 Edge/去水再编故事；只凭即时 SP 或孤立 Edge 定出票；竞彩现盘写成真开盘水位路径。

- 胶着/空槽/方向空着；没有一侧却硬装成主不败或主胜/客胜/平；观望不写弃因；观望场进票；赛后把已写倾向改成观望；研究板偏薄硬砍冷侧；假热排冷侧无硬情报。
