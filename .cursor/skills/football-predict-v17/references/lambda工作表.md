# λ 工作表 · 唯一口径

用途：把 λ 从「读完情报凭感觉拍一个数」变成可复算、可归因的固定算法。任何一场的 λ_H/λ_A 都必须能按本表拆出每一层；拆不出来就降级为人工估计并放宽区间，禁止伪装成工作表输出。

## 第 1 层 · 联赛基准

| 输入 | 含义 | 取数 |
|---|---|---|
| `LgH` | 联赛/赛事主场场均进球 | 本赛季同赛事均值；无数据用默认 |
| `LgA` | 联赛/赛事客场场均进球 | 同上 |

默认基准（无可靠联赛均值时）：欧国联/国家队正式赛 `LgH=1.35, LgA=1.05`；友谊赛两边各 +0.10；主流俱乐部联赛 `LgH=1.50, LgA=1.15`。默认值必须在 `区间依据=` 里注明「默认基准」。

## 第 2 层 · 攻防强度（带样本收缩）

```text
att_H = 主队主场场均进球 / LgH      （主队主场攻击）
def_H = 主队主场场均失球 / LgA      （主队主场防守，越小越好）
att_A = 客队客场场均进球 / LgA      （客队客场攻击）
def_A = 客队客场场均失球 / LgH      （客队客场防守）
```

- 样本不足向 1 收缩：`强度 = 1 + (实测强度 - 1) × n/(n+k)`，n=该口径场次，k=5（待账本标定，禁止拍成别的数还自称工作表）。
- 对手强度修正：样本期内对手明显偏强/偏弱时，先把实测进失球按对手档次粗调再算强度，并在文中写一句依据；调不动就放宽区间，不硬调。

## 第 3 层 · 基础 λ

```text
λH_base = LgH × att_H × def_A
λA_base = LgA × att_A × def_H
```

## 第 4 层 · 修正项（每项必须有证据）

| 修正 | 单项范围 | 何时用 |
|---|---|---|
| 伤停/阵容 | 0.85～1.15 | 关键球员角色、替补差距、对位写清楚才可用 |
| 赛程/体能 | 0.90～1.10 | 连续客场、周中双赛、长途旅行 |
| 战意/赛制 | 0.90～1.10 | 出线形势、保级、友谊赛轮换，需证据不编战意 |
| 战术对位 | 0.90～1.10 | 明确风格克制/被克制 |

`adj = 各项连乘`，总修正限制在 **0.70～1.30**；超出说明证据叠加过度，回去删修正而不是硬填。

```text
λ_H = λH_base × adj_H
λ_A = λA_base × adj_A
```

## 第 5 层 · 区间

```text
u = 0.15（基准）
  + 0.05（样本 n < 8）
  + 0.05（关键阵容/首发未确认）
  + 0.05（友谊赛或大幅轮换预期）
  上限 0.35
λ区间 = [λ × (1-u), λ × (1+u)]
```

## 工具

```bash
python3 scripts/lambda_sheet.py --league-home 1.35 --league-away 1.05 \
  --att-h 1.55 --def-h 0.85 --att-a 0.90 --def-a 1.10 \
  --adj-h 0.95 --adj-a 1.05 --n-h 10 --n-a 10
```

输出 λ_H、λ_A、λ区间，并直接给出可粘贴的 `conservative_probability.py` 命令。工作表输入必须在正文保留一行分解：`基准=｜攻防=｜修正=｜收缩=`，让任何读者能复算。
