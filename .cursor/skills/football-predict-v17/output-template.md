顺序检查：取证 → 情报 → 球队 → 剧本（含反剧本收据若触发）→ 硬闸/Edge → **研究推荐** → 出票。颠倒 = 废稿。

几何检查：高结构同族三联 = 废稿；低结构防弃权无旁 = 废稿。
TOP 软清单：只约束研究 TOP 席位/星级上沿；**不**改剧本方向、**不**当出票弃单理由。
