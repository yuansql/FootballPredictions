# football-predict-v17 术语表（Phase A）

> 本表用于降低执行歧义。每次输出中首次出现术语时应给出中文解释，后续可缩写。

## 一、核心工作流

| 术语 | 中文 | 一句话定义 |
|------|------|-----------|
| **INTEL_FIRST** | 情报优先 | 比赛分析从伤停、战意、赛程、主客场、H2H 等情报开始，赔率只作为辅助闸门。 |
| **双轨推荐** | 双轨推荐 | 研究推荐（01，场场必出）与出票推荐（02，可空仓）分离。 |
| **情报叙事** | 情报叙事 | 把离散情报组织成有因果关系的球队/比赛故事。 |
| **球队画像** | 球队画像 | 对主/客队形态、火力、防守、风格的结构化描述。 |
| **比赛剧本** | 比赛剧本 | 对比赛进程的方向、进球档、情景路径、HT/FT 的综合叙事。 |

## 二、方向与输出纪律

| 术语 | 中文 | 一句话定义 |
|------|------|-----------|
| **方向** | 1X2 方向 | 锁主/锁客/锁平，或主不败/客不败。认真拆必须给。 |
| **胶着** | 胶着 | **4.22.3 禁用**。旧稿三向 scout，会把方向刷成永远命中。 |
| **主不败** | 主不败 | 允许集={主胜,平}；客胜=方向 miss。 |
| **客不败** | 客不败 | 允许集={客胜,平}；主胜=方向 miss。 |
| **并列** | 并列 | 两个方向同时高权重，只并所写两边，不等于三向。 |
| **低结构** | 低结构 | 方向未焊死或权重差 < ε，禁止进 TOP2；可比分弃权。 |
| **高结构** | 高结构 | 方向焊清、收据过闸、#3-#4 margin≥ε。 |
| **主推 / 次 / 防** | 主/次/防 | 比分推荐的三个权重单格；没把握可整篮弃权。 |
| **旁挂 / 旁注** | 旁注 | 公开篮外的逃生比分。 |
| **一原子合同** | 一原子合同 | 锁单例时两格同一 1X2；主不败可主+平，客不败可客+平。 |
| **空槽** | 空槽 | **4.22.3 新稿禁止**。旧稿不进命中率分母。 |
| **skip** | skip | 仅遗留空槽的 RMA 值。 |
| **锁平 / 锁主 / 锁客** | 锁 | 对单一 1X2 的明确断言；锁平须含 0-0 或闷平证据。 |

## 三、反剧本与审计

| 术语 | 中文 | 一句话定义 |
|------|------|-----------|
| **反剧本收据** | 反剧本收据 | 使用复仇/焊平/管理晋级/德比谨慎标签冲 TOP 前，必须提交的 counter_direction 等字段。 |
| **weld_tag** | 焊标签 | 把方向焊成唯一主轴的叙事类型：revenge_home、weld_draw、manage_tie、derby_caution、continuation_guest。 |
| **counter_direction** | 反方向 | 收据中必须填写的最强反方向。 |
| **clause_id** | 条款 ID | 收据中引用的规则条款，如 script#1、soft#2。 |
| **RMA 双仓** | RMA 双仓 | 方向仓（direction_rework）与比分仓（score_rework）分开归因复盘。 |
| **RMA 路由** | RMA 路由 | 赛后给每场判定的分类：direction_rework / score_rework / closed / skip。 |
| **fingerprint** | 收据指纹 | `{weld_tag, clause_id, counter_direction, intel_slot_shape}` 的结构化归类。 |
| **shadow 闸** | shadow 闸 | 同指纹近 N 条方向 miss ≥2 时给出警告；≥1 counter_hit 时 live 禁 TOP2。 |
| **三本账** | 三本账 | 复盘命中率必须同屏展示：对外三场 / 01篮 / 全表。 |

## 四、赔率与闸门

| 术语 | 中文 | 一句话定义 |
|------|------|-----------|
| **SP** | 官方赔率 | 体彩官方给出的赔率，已含抽水。 |
| **RAW** | 原始概率 | 从 SP 去水后的原始概率估计。 |
| **λ / λ′** | 泊松参数 | λ 为模型基础进球率，λ′ 为 patches 调整后的进球率。 |
| **Edge_raw** | 原始 Edge | RAW 概率与模型概率的差值（未扣抽水）。 |
| **Edge_eff** | 有效 Edge | 扣除体彩抽水后可真实期望的 Edge。 |
| **双闸门** | 双闸门 | 胜平负通道 ≥1%，让球/进球数通道 ≥3%（≥5% 可标高推）。 |
| **降维** | 降维 | 胜平负无 Edge 时，尝试让球或进球数子盘。 |

## 五、V15.6 补丁

| 术语 | 中文 | 一句话定义 |
|------|------|-----------|
| **StarFactor** | 星因子 | 客队传统三强 + 后防伤≥2 + 中前场全勤 + 客胜赔≤1.50 时，子盘 λ 上调。 |
| **Kryptonite** | 客队克星 | 客队近 10 交锋 ≥8 胜时，P_A 偏移后归一化。 |
| **Jinx** | 主场平局咒 | 主场近 5 交锋 ≥3 平时，P_D 6:4 平滑。 |
| **Zombie** | 深盘陷阱 | 主队垫底 2 + 胜≤1 + 受让≥1 时，让球 Edge 打折并预警。 |
| **Edge_Refine** | Edge 精炼 | 主盘 Edge_eff≤-5% 时做冷门扫描，≥3% 仅改出票提示。 |

## 六、Soft / Discipline / Forbidden

| 术语 | 中文 | 一句话定义 |
|------|------|-----------|
| **软清单** | 软清单 | 约束研究 TOP 席位/星级的 7 条规则，不改剧本方向。 |
| **纪律** | 纪律 | 写剧本/比分时的 12 条质量约束。 |
| **禁止清单** | 禁止清单 | 会导致输出无效或命中率口径造假的行为清单。 |
| **噪点纪律** | 噪点纪律 | 单次偶然 MISS 不加规则，须同类 ≥2 或结构性错误。 |
