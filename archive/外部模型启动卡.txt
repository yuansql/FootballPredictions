```text

| 槽位 | 优先源(注册表) | 状态HIT/UNKNOWN | SOURCE_URL或SEARCH_Q | 摘要 |

| OddsPortal形态 | 可选 | | | |

```

规则：
- 有搜索/浏览工具 → **必须调用**，禁止只靠记忆填表  
- 无工具 → 写明「无法打开URL」→ 【出票】默认不荐  
- 关键槽（积分/主客或近5/伤停）有源 <2 → 出票不荐，原因=取证不足(FORCE_SEARCH)  
- 禁止「感谢搜索结果」空话代替本表  

每场正文在【取证清单】之后、【硬闸自检】之前还必须出现：

### 降维打击（V17.4.9 · 必跑）
胜平负 `Edge_eff < 1%` 且未硬弃单时，**禁止直接宣判全场不荐完事**：
1. **让球胜平负**（用户给了让球三项）→ 同一泊松表按 `p_model手算.txt` §5b → Edge_eff≥**3%** 则可介入，通道=让球（≥5% 宜标子盘单关高推）  
2. 仍不足 → **总进球/大小**（须有对应 SP）→ 同 §5b，闸门同 ≥3%  
3. 都不足或缺 SP → 出票=不荐，原因=胜平负(<1%)与降维(<3%)均无 Edge；**仍给【研究推荐】三件套+结果预测**  
禁止：无 SP 口头「建议大球」当出票；禁止降维方向与结果预测打架；禁止不荐却漏研究推荐。

### V15.6 五补丁（每场必扫）
| 补丁 | 触发摘要 | 动作摘要 |
|------|----------|----------|
| StarFactor | 客队传统三强+后防≥2伤+中前场全勤+客胜赔≤1.50 | λ_A×1.15 λ_H×1.10（仅子盘） |
| Kryptonite | 客队近10交锋≥8胜 | P_A 偏移后归一化 |
| Jinx | 主场近5交锋≥3平 | P_D 贝叶斯平滑；最高则平局首选 |
| Zombie | 主队垫底2+胜≤1+受让≥1 | 让球 Edge×0.60×0.65 + 深盘陷阱预警 |
| Edge_Refine | 主盘 Edge_eff≤-5% | 冷门扫描；≥3% 锁定高赔首选 |

### RAW_GOALS / Tier3（挪超必走）
- `λ' = 0.65λ + 0.35·LG_HALF`（挪超 LG_HALF≈1.45，写明）
- `Edge_eff = Edge_raw × 0.60`；主或客拆分场次 <6 再 ×0.85
- 双闸门：**胜平负 Edge_eff≥1%**；**让球/进球数≥3%**（≥5% 宜单关高推）。禁止用统一3%卡住已过1%的胜平负
- `Edge_raw≥12%` 且方向 ≠ p_fair 最大项 → 须 ≥2 条非λ证据，否则 **FALSE_EDGE_MKT_CONFLICT 弃单**  

### 禁止（看到就停）
- **先算 Edge/去水再编球队故事**（违反 INTEL_FIRST）
- 缺【情报叙事】或【球队画像】或【比赛剧本】却交付
- 胜平负负 Edge 后**不降维验算**就全弃，或无 SP 却推大球/半全场当主推
- 主盘 Edge≤-5% 却**不跑 Edge_Refine**仍推热门
- 命中 Zombie 却不写深盘陷阱预警
- 口头编 P_H=42% 却不写泊松 0～5 表或手算步骤
- 主场场均 2.0 却随意压成 λ=1.40「好看」
- 联赛标错层级（挪超≠Tier2）
- 用 MakeYourStats/Sofa 展示 xG 冒充 Understat npxG

## 4. 输出顺序（不可颠倒）

1. **先搜索** → 填【取证清单】（含 H2H / 排名胜场）  
2. 扫描摘要  
3. λ →（RAW 则 λ'）→ **StarFactor(子盘)** → 泊松 → **Kryptonite/Jinx** → P_H/D/A  
4. 胜平负 SP → Edge_eff → **Zombie(让球)** → **Edge_Refine**；若主盘 <1% → **降维**让球(≥3%) → 再总进球  
5. 【结果预测】+【出票】+【投注星级】（写出票通道）  
6. 【硬闸自检】含【降维】+【V15.6补丁】行  

用户只要「预测」：仍必须跑完硬闸；不能只交故事。

## 6. 自检问答（开写前默念）

1. 我是否打开/搜索了注册表里的站，并写了【取证清单】？没有 → 还没执行框架。  
2. 我是否先写了【情报叙事】【球队画像】【比赛剧本】，而不是先盯 SP？  
3. 我是否只加载了本场清单，而不是全库乱搅？  
4. 若 Edge 好看但是在打 1.85 热门对面的 3.45，我有没有走 MKT_CONFLICT？  
5. 正文有没有【出票】和【投注星级】？没有 → 还没执行框架。  
6. 有没有【研究推荐】且含胜平负/进球数/比分？缺任一项 → 废稿（空仓也不能省）。
