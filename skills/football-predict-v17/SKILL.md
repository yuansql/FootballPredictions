# 2足球框架 V17.4.21 · 情报优先执行器（精简包 · 双轨推荐）

## 总原则（最高优先）

**足球分析的乐趣与正确顺序在情报与球队，不在赔率算术。**

| 层级 | 内容 | 角色 |
|------|------|------|
| 主菜 | 伤停/战意/赛程负荷、主客形态、风格克制、H2H 定性、比赛剧本 | **定方向与比分叙事** |
| 佐料 | 让球盘口、胜平负/子盘 SP、Edge_eff、双闸门、降维 | **只决定下不下、下多大** |

禁止：先盯 SP/Edge 再倒推方向；禁止全文只剩去水算术、没有球队故事。  
冲突：本 skill > 主控 > 人设 > 插件。

### 双轨推荐（V17.4.9 · 空仓也要有推荐）

| 轨 | 字段 | 空仓时 |
|----|------|--------|
| **研究推荐** | 【研究推荐】五星 + **胜平负** + **进球数** + **比分**（主/次/防） | **场场必出** |
| **出票推荐** | 【出票】可介入/不荐 + 【投注星级】 | 可全不荐（☆☆☆☆☆） |

禁止：只写「不荐」却不交研究三件套；禁止用【投注星级】冒充【研究推荐】。  
多场日：文末加【今晚研究 TOP】（按研究星级排序，≤3；不涉及仓位）。

### 研究 TOP 软清单（V17.4.9+ · 2026-08-13 v2 · 非弃单硬闸）

排【今晚研究 TOP】前自检（**只约束研究 TOP 席位/研究星级上沿，不改【比赛剧本】方向，不做出票弃单理由**）：

1. 主胜 SP≤**1.50** 且非λ证据几乎只有「主场/名气」→ 研究星级封顶 **★★★☆☆**，**默认不进 TOP2**（可进 TOP3 或降权区）。  
2. 杯赛/欧战**次回合**且一方首回已领先 → 「客不败/管理比赛」**不得默认满星进 TOP3**；须另有伤停/形态证据，否则降权或旁注。  
3. 德比 或 首回 **0-0** 定生死 → **默认降权出 TOP**（宁缺毋滥，勿硬凑满 3 席）。  
4. 杯赛/解放者杯/欧战资格 **首回合主场** → **默认不进 TOP1**；进 TOP2 须剧本**硬写防平**（1-1/0-0）。  
5. **刚大胜/屠杀**后短期复赛（近 1 场净胜≥4 或公开屠杀叙事）→ **不满星 TOP1**（可旁注/降权）。  
6. 欧战/杯赛拟进 TOP 前须显式 **90′ 自检**：晋级故事/加时/点球 **≠** 竞彩胜平负三点。  
7. **continuation_guest**（同址七日客队刚赢再战）：默认研究星封顶 **★★★☆☆**、**不进 TOP2**；进 TOP3 须客上轮净胜≤1 **且** 主核心缺阵≥2。禁止把「主场讨债」默认焊成 TOP1。

**噪点纪律**：单次偶然 MISS 不进清单；须同类复盘 MISS≥2 **或**结构性口径错误（如 90′）才加条。禁止把软清单升成出票弃单/改剧本方向。禁止叠「揭幕日」「心情分」等模糊条。

来源：08-05/06 初版；08-10～12 头条复盘补 4–6（普拉滕斯首回平、佐加顿斯屠杀复赛、博德 90′）。

### 方向优先 · 反剧本收据（V17.4.15 · 2026-08-26 · ADHD/08-25 复盘）

**优化序**：先把胜平负方向焊对，再谈比分篮宽。比分纪律（下节）不替代本条。

写【比赛剧本】**方向**时，若使用下列叙事标签之一焊成**唯一主轴**（或据此冲 TOP1/TOP2），必须先交**【反剧本收据】**，否则方向降为胶着/并列，研究星封顶 **★★★☆☆**，**不得进 TOP2**：

| 标签 | 典型焊法（须收据） |
|------|-------------------|
| `revenge_home` | 主场讨债 / 同址刚输要面子 |
| `weld_draw` | 势均→焊死平局三点 |
| `manage_tie` | 领先方管理比赛 / 输一场仍晋级（90′） |
| `derby_caution` | 德比/揭幕只写谨慎闷 |
| `continuation_guest` | 同址客刚赢再战却焊主胜讨债（默认降权，见 TOP 软清单#7） |

**【反剧本收据】必填字段**（可进 `01` 场次段或框架输出）：

1. `counter_direction`：最强反方向（主胜|平|客胜）  
2. `counter_one_liner`：反剧本一句话（须能对上取证槽，禁空话）  
3. `why_reject`：为何仍拒反剧本（伤停/战意/形态，有源）  
4. `clause_id`：授权本焊的纪律条款（如 `script#1`…`script#9` / `soft#6`）  
5. 若拒不干净（说不清反剧本为何弱）→ **不得焊死**：方向改胶着或并列双路径

赛后复盘对账：`counter_hit`（其实反剧本对了）vs `weld_ok`（主轴成立）vs `weld_failure`（条款失灵）。用条款热力图改 margin，**禁止**单次 MISS 直接加软清单行。

来源：08-25 森林讨债 / 瓦伦焊平；ADHD 短名单「反剧本收据」。

| `scripts/lint_draft.py` | 01/03 发前 warn lint |

| RMA | 条件 | 只答 |
|-----|------|------|
| `direction_rework` | 1X2 方向 miss | 三问之 **① 方向为啥对/错**；禁展开「若方向对了比分…」 |
| `score_rework` | 方向对、精确分未挂进主/次/防/旁 | 三问之 **② 比分为啥挂/没挂**；禁重审方向 |

≥2 同 clause 热力 **或** 结构性 90′ 口径错 → 才提案改 skill（一仓一刀）。

可跑 `scripts/lint_draft.py <日夹|01|03> --warn-only` 做发前/复盘 warn。

### 对外钉槽 · 类比符号 · 三本账（V17.4.21 · 2026-08-28 · ADHD）

**不是软清单新条。** 08-27 认真三场方向 1/3：可校准热门被踢出镜头后仍「钉三场」；`并列` 曾被脚本扩成三向。

1. **看槽 ≠ 钉槽（头条 02）**：认真拆 ≥3 是骨架（环境维/上下半场/进球点）。「今晚我钉 K 场」只许抄未标「不进 TOP2 / 别拿主胜凑席」且能写清 90′ 方向的场；**K 可为 0–2**。`01` 已宁缺 TOP2 → 禁止 `02`「今晚我钉三场：A、B、C」。权威仓内 `toutiao-publish.md`。  
2. **胶着不得对外收窄**：`01` 方向胶着/低结构，研究行与 `02` 禁止收成更窄的主不败/平客。  
3. **类比符号三元组**：写「里昂课 / 结构同类」须 `(追分|领先) × (主|客) × 分差`；符号不一致禁止调用该课。`02` 标题晋级主语不得复制进 90′ 方向行。  
4. **RMA 对外入口**：对账方向喂 `02` 句面，禁止喂 `01`「胶着」冒充命中。`normalize_direction`：**并列 ≠ 三向**（胶着仍三向，仅限 01）。  
5. **三本账**：`03` 若写命中率分数，必须同屏 **对外三场 / 01篮 / 全表**。禁只甩 1/3。口头先报真 miss。

脚本：`rma_route.py` · `lint_draft.py`（日夹 ≥2026-08-28 钉槽/符号；≥2026-08-27 三本账）。

### 比分推荐 · 单格 Top3（V17.4.20 · ADHD）

**顺序硬**：双方分析/剧本 → **方向锁** → **进球档** → 写 **【情景路径】**（2–4 条，`weight`+终场叶）→ **每个比分单独计权** → 取权重 **Top3 单格** → 公开 **≤3**。  
**禁止**把三格当套餐。每个比分（2-1、1-0、2-0、1-1…）**独立**计权。  
第3与第4单格权重差 **&lt;ε（默认 0.15）** → **低结构**（只交权重 Top2，防弃权）。

| 结构档 | 何时 | 装箱 |
|--------|------|------|
| **低结构** | 胶着/并列、收据拒不干净、**ε 胶着**、无焊唯一主轴 | 只押 **主+次**；**防=显式弃权**；逃生写 **旁注** |
| **高结构** | 方向焊清、收据过闸、#3-#4 margin≥ε | 主/次 = 焊轴族单格 #1/#2；**防** = 平防 **或** 收据 ±1 球反方向（见下） |

**收据防格（V17.4.20 · 比分仓）**：【反剧本收据】过闸且 `counter_direction` 与焊轴**异号**时，须有一条情景叶 `weight≥τ（0.10）` 的 **±1 球**反方向分（主胜焊→**0-1**；客胜焊→**1-0**），占用公开 **防**。02 可写「真爆冷最像 0-1」。屠杀/多球反方向仍旁注。主+次不得混异族。  
**同链反回声**：情景叶与公开格全是同一胜族、无 1-1/反方向 → 视为双计，须换防格。  
**HT/FT 分轨**：`ht_path_A/B`（半场态）与 `path_A/B/C`（90′ 终场）分开写。`derby_caution` / `weld_draw` / 谨慎闷 → 必须有 **开口/对方先破门** 备路径（#8）。02 只留「上半场主/备」两句。  
**TOP2 预闸**：低结构不得进 TOP2；焊标签须 `clause_id` 绑 path 叶；同指纹 **1 次** `counter_hit` → live 禁 TOP2（不等 ≥2）。  
**禁止**：无路径任选；三格套餐。  
**旁注**：#9 屠杀/多球逃生；收据未过闸时的异族 ±1 球。收据过闸后 ±1 球进 **防**，进 `02`。  
**废止**：邻格主闸（V17.4.17）；同等合法/两簇任选（V17.4.18）；三格套餐（V17.4.19 初版）。  
**交卷口吻**：`02` 球迷话；weight / τ / margin 留 `01`。  
脚本：`score_geometry.py`（`pick_counter_leaf` / `lint_anti_echo`）· `lint_draft.py` · `receipt_fingerprint.counter_hit_shadow_check`。

### 剧本 / 比分推荐纪律（V17.4.20 · 2026-08-27 · 球迷+分析师准确率闸）

写【比赛剧本】与【研究推荐】比分时（**改推荐质量，不做出票弃单理由；单场 MISS 不加软清单条**）：方向未过「反剧本收据」闸前，**禁止**先扩比分篮假装完成。

1. **环境维不焊方向**：天气/场地/湿度等只加权，**禁止单独焊死**胜平负方向。中游主场打争冠/榜眼客：须并列写清 **「主队先破门 → 主胜或平」** 路径，不得只留客胜主轴。  
2. **逃生口**：收据**未**过闸 → 相反 ±1 球只写 **旁注**。收据**已**过闸 → 该 ±1 球占公开 **防格**（τ≥0.10）；多球/屠杀仍旁注。开口平局研究侧可旁挂 **2-2**。  
3. **上下半场分轨**：HT 与 FT 分开写；HT 主轴与终场方向同号时必须有 **对方先破门** 备路径。比分三格对双方路径，不是几何凑邻。  
4. **进行中大比分 ≠ 终场**（08-15 米亚尔比 0-3→4-3）：上半场屠杀成立时，下半场仍须保留 **落后方追分/翻盘** 终局；禁止用半场比分锁死 90′ 方向推荐。  
5. **体能税不焊小胜上限**（08-15 威廉二世 1-4）：中周 120′/短间隔只加权；纸面明显优时 **旁注** 留大胜（如 1-4 / 0-3）。  
6. **揭幕/小球教练画像不焊平**（08-15 阿拉维斯 3-0）：揭幕战不得单独焊死平/小球；主场揭幕须并列 **主胜多球** 旁注。  
7. **领先两球 ≠ 终场锁定**（08-16 阿贾克斯 2-0→2-2、桑坦德 2-0→2-2）：研究侧可旁挂 **2-2**；公开三格按单格权重（可含 1-1 防平）。  
8. **双新帅揭幕 / 同城德比不焊「谨慎闷半场」**（08-24 富勒姆 2-3 切尔西）：须并列 **「开场见球 / 开口」**（`ht_path_B`）。开口篮旁注可挂 **2-3 / 2-2**。  
9. **须屠三球的次回合翻盘 · 旁挂多球**（08-25 林茨 4-1 凯尔特人 90′）：须净胜≥3 时 **旁注** 挂 **3-1 / 4-1**；公开 Top3 若分析把屠杀分排进前三则可进格。加时/点球≠竞彩 90′。  
10. **双方分析 → 单格 Top3**（V17.4.19+）：每个终场分单独计权；**禁止**邻格/套餐。margin&lt;ε → 低结构。  
11. **同链反回声**（V17.4.20）：伤停/形态与球迷 anecdote 不得当两条独立信号把三格全焊成同一胜族；防格须换异链路（平或收据反方向 ±1）。  
12. **continuation_guest**（V17.4.20）：同址客刚赢再战，禁止默认复仇 TOP1（见软清单#7）。

来源：`toutiao/drafts/2026-08-14`～`08-25` 复盘；`2026-08-26/27` ADHD（单格计权 → 球迷+分析师准确率闸）。

### 复盘 → skill 闭环（同日）

### Edge 诚实声明（体彩）

体彩官方 SP 抽水厚，RAW 口径再打折后，**多数场次 Edge 为负属正常**。  
普通玩家「赢」靠：**情报定剧本 + 多数空仓 + 闸门真开才出手**；不靠场场击穿官网定价。  
负 Edge → 【出票】不荐；**仍必须交【研究推荐】三件套（胜平负/进球数/比分）+ 情报/剧本**。

5. **盘口辅助**：读让球线与 SP → λ（RAW→λ′）→ StarFactor(子盘) → 泊松 → Kryptonite/Jinx  
6. **出票闸门**：胜平负 Edge_eff；≥**1%** → 通道=胜平负；**<1%** 且未硬弃 → **降维**让球→进球（≥**3%**；≥5% 可标单关高推）  
7. **Zombie / Edge_Refine** → 【出票】【投注星级】（出票星；降维≤★★★☆☆）+ **【研究推荐】**（研究星 + 胜平负/进球数/比分）  

硬弃单 → 【出票】不荐；**仍必须【研究推荐】三件套 + 情报+剧本+结果预测**。

## 双闸门（出票用 · 非方向用）

| 通道 | Edge_eff 闸门 | 实战含义 |
|------|---------------|----------|
| 胜平负 | **≥ 1%** | 击穿体彩抽水后的可介入门槛 |
| 让球 / 进球数 | **≥ 3%** | 子盘方差大；≥**5%** 宜标「高赔单关主推」 |

Edge **不得**改写已定剧本方向与【结果预测】。  
**Edge_Refine / MKT_CONFLICT**：最多改【出票】提示；**禁止静默覆盖【比赛剧本】【结果预测】**。  
降维方向与结果预测打架 → **出票不荐**（禁止推打架的让球/进球）。
