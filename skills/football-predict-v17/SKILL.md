# 2足球框架 V17.4.52 · 情报优先执行器（精简包 · 双轨推荐 · 票面优先 · 跨玩法串 · 自研）

## 总原则（最高优先）

**足球分析的乐趣与正确顺序在情报与球队，不在赔率算术。**

### 交卷模式二分（V17.4.50 · **主交卷随模式 · V17.4.51/4.52**）

每篇 `01` 文首必须点名一种（可并存时以点名的为准）：

| 模式 | 第一读者问题 | **主交卷** | 票面 | 方向强制 |
|------|--------------|------------|------|----------|
| **研究板** | 方向/比分/扫盘怎么看？ | **【全场汇总表】+ 扫盘**（比分见薄情报闸） | 块仍必有；**默认空仓合格** | 可 `观望/不定罩` 或 `不败｜弱置信=是` |
| **下注单** | 今天小票买什么 / 为何空仓？ | **【今日票面】** 可买腿（或空仓弃因） | **主 KPI=票中** | **必须**锁\*/不败（禁观望充数） |

```text
交卷模式=研究板｜或｜下注单
```

禁止用「下注单」叙事却只交方向表；禁止「研究板」却逼场场可介入或凑票面腿。亲爱的未点名时：说「给分/扫盘/不推票」→ 研究板；说「最少二串一/推票」→ 下注单。

**研究日复盘口径（V17.4.52）**：`交卷模式=研究板` 且票面空仓时，口头「调中了没」→ 指汇总表 **方向仓 + 比分仓（若有装箱）**；**不以票中/票面 3/3 当主 KPI**，空仓不算 FAIL。

| 层级 | 内容 | 角色 |
|------|------|------|
| **主菜** | **排除**（可 `暂缓`）→ **方向** + 伤停/战意/赛程、形态、克制、H2H、剧本 | **定 1X2 与比分叙事** |
| **佐料** | **初盘（须标类型）** + 水位路径 + 现 SP/让球（+ Edge 仅可介入） | **扫盘/出票**；否证可回流改方向 |
| **临场** | XI | 日间研究免写；真下/T-60 才核 |
| **票面** | 【今日票面】 | 研究板默认可空；**仅下注单**当主交卷 |

### 佐料整包（V17.4.32 · 初盘为锚 · **V17.4.50 初盘诚实**）

**怕什么**：SP 会漂；更怕把「竞彩现盘」假扮成真·亚欧开盘路径。  
**定什么**：锚必须**标类型**；没有真开盘就承认缺，禁止写完整水位故事充数。

| 初盘类型（扫盘行必选一） | 含义 | 水位怎么写 |
|--------------------------|------|------------|
| `初盘=真开盘` | 有亚盘/欧赔开盘价可核 | 初→现路径可写撤热/灌热/背离 |
| `初盘=竞彩现盘` | 仅有竞彩即时让球/SP | 只写「竞彩现盘对照」；**禁止**假装亚欧开盘路径 |
| `初盘=缺` | 两边都没有 | 水位写 `缺`；**禁止**可介入；研究板仍可给方向 |

| 零件 | 性质 | 用法 |
|------|------|------|
| **初盘（类型见上）** | 锚 | 结构深浅、站哪边 |
| **水位** | 路径或「仅现盘」 | 真开盘才谈路径；竞彩现盘只对照支持率/让球民意（**辅证**，非聪明钱） |
| **现 SP + 让球** | 快照 | 须与初盘类型同屏 |
| **Edge / 泊松 / V15.6** | 出票算术 | **仅认真拆且【出票】可介入/试探**；观察骨架 / 研究板观望 **免扫 V15.6** |

**硬规则**：
1. 扫盘/出票须写：`初盘=真开盘|竞彩现盘|缺` +（非缺时）现 SP/让球；可介入另加水位路径与 Edge/通道。  
2. **禁止**只报即时 SP 定可介入；**禁止** `初盘=缺` 仍写「水位完整/初盘为锚已看」。  
3. 佐料默认不改方向；否证回流例外同 4.47（须 `对照盘口修订=`）。  
4. **竞彩支持率**=民意辅证，上限：可印证背离/热度，**不得单独**焊锁\*或单独定排除。  
5. **盘口可见序（V17.4.51）**：允许**先看结构盘**（让球深浅、是否只开让球、现盘热侧）再写剧本；冻的是**方向结论**（见【方向冻结】），不是假装没见过 SP。禁止装盲测。

**日闸**：`SEASONING_DAY=2026-09-17`；交卷/初盘/冻结 `DELIVERY_DAY=2026-09-22`；流程消矛盾 `FLOW_FIX_DAY=2026-09-22`；弱方向/假热/薄比分 `JUDGE_FIX_DAY=2026-09-22`。

| 否证触发（≥1） | 动作 |
|----------------|------|
| 水位/现盘相对**已冻方向**剧烈背离（撤热/灌热/跨市场打架） | 回流重判方向；可降不败或改锁 |
| λ′ 与已定方向**严重打架** | 回流；或出票强制观望 |
| 临场伤停/主力落选**爆出** | 回流或撤票面腿 |

### 伤停未知封顶（V17.4.50 · P1 · **薄情报比分 V17.4.52**）

取证槽 `伤停=` 若为 **未知 / 未见 / 无可靠源 / 槽弱**：

1. **禁止**写 `ICS=…｜PROCEED` 或 `情报档=充足｜PROCEED` 装情报齐全。  
2. 情报档最高 **偏薄/CAUTION**（或显式 `情报档=偏薄｜CAUTION｜伤停未知`）；研究星封顶 **★★★☆☆**；**不得进票面 TOP1**。  
3. 杯赛揭幕 + 伤停未知 → 默认叠加轮换风险，倾向优先 **不定** 或降不败 / 观望。  
4. 伤停有源（名单/新闻 URL）才可 PROCEED（仍须其它槽达标）。  
5. **（V17.4.52）研究板比分**：伤停未知 **或** `情报档=偏薄|不足` → **默认比分弃权**（进球区间仍必出）；亲爱的点名「要好看/给分」才装箱，并写 `弱置信=是`。禁止 ★★★ + 三格填满却不标弱置信。

### 弱置信方向 · 研究板观望（V17.4.52 · P0）

**怕什么**：U23/揭幕/伤停未知场被流程逼出「排除客胜 + 主不败」假砍 → 排除仓好看、实战客胜一穿。  
**定什么**：低情报允许诚实 lean+pass；**仅下注单**强制可结算方向原子。

| 交卷模式 | 允许的方向写法 |
|----------|----------------|
| **研究板** | `锁*|主不败|客不败`；**或** `方向=观望` / `方向=不定罩`（仍给进球+扫盘）；**或** `方向=主不败｜弱置信=是`（偏薄时不败须标） |
| **下注单** | **必须** `锁*|主不败|客不败`（可写弱置信，但禁观望充腿） |

```text
方向=观望｜弱置信=是｜进球=1-2｜一句=情报偏薄不写死1X2
方向=主不败｜弱置信=是｜单子腿=不定
```

- `情报档=偏薄|不足` 或伤停未知：研究板 **默认**暂缓排除 + 观望/弱置信不败；禁止硬砍冷侧充排除仓。  
- 观望/不定罩：汇总表「推方向」写 `观望`；单子倾向=`不定`；**不得**进票面腿。  
- **禁止胶着三向永远命中**；观望 ≠ 胶着（胶着是假原子，观望是显式 pass）。

### H2H 正式/友谊分层（V17.4.51 · P1）

取证写 H2H 时须标赛事性质：

```text
H2H=正式|友谊|混｜近N=…｜权重=正式优先
```

- **正式**（联赛/杯赛/欧战正式阶段）可进排除/方向硬论据。

- 混写时须点明「正式侧」结论；禁止把友谊赛屠杀当档差铁证。

**情报纪律 · 联赛形态外推欧战（V17.4.25 · 2026-09-09 · 欧冠复盘补丁）**

禁止：先盯 SP/Edge 再倒推方向；禁止全文只剩去水算术、没有球队故事。

| 主不败 | **复式：主胜+平**（花2倍本金）；或单买 **让球主胜**（若让球盘主让球） | 方向偏主但防平 |
| 客不败 | **复式：客胜+平**（花2倍本金）；或单买 **让球客胜**（若让球盘客让球） | 方向偏客但防平 |

**出票层强制规则**：
1. 方向为 主不败/客不败 时，【出票】段**必须**写 `"复式 主胜+平"` 或 `"让球主胜"` 等实际操作，不能只写"主不败"。
2. 方向为 锁主/锁客/锁平 时，【出票】段写 `"单买 主胜"` 等即可——**前提是胜平负已开售**（见下节 V17.4.36）。
3. 出票默认观望时，仍须写明观望理由（如"低结构，Edge 不足"）。

**怕什么**：只推胜平负（含复式不败），让球盘明明更稳却不说；或反过来把「让球」理解成「只能单买、禁止串关」。

### 跨玩法二串一（V17.4.42 · 2026-09-22 · 亲爱的点名）

**怕什么**：票面/研究串被理解成「只能让球串」或「只能胜平负×胜平负」；玩法开售不齐时硬写买不到的腿。  
**定什么**：**二串一（及票面过关）允许跨玩法组合**——胜平负、总进球数、比分、让球胜平负、**半全场**，**只要该场该玩法已开售**即可进同一张串。

| 腿类型 | 必须满足 | 禁止 |
|--------|----------|------|
| **胜平负** | 该场胜平负已开售；选项=汇总表「单子倾向」（主胜/平/客胜）；不定不拼 | 用不败当腿；未开售场写单买主胜 |
| **总进球数** | 该场进球玩法已开售；档位从本场已写「推进球/进球区间」收成（可双选两档） | 另开与剧本矛盾的进球故事 |
| **比分** | 该场比分玩法已开售；选项 ∈ 本场主/次/防（或旁注已写明） | 钉剧本外冷门分充数 |
| **让球** | 让球已开售；写清盘口+让球主胜/让平/让负 | 冒充 A 区胜平负腿不标注通道 |
| **半全场** | 该场半全场已开售；半场路径与 `ht_path` / 终场方向同故事（可写胜胜/平胜/胜平等） | 与剧本半场备叶矛盾的乱钉 |

**组单口径**：
1. 【研究二串一】须分块写清：`A 胜平负` / `B 让球` / `C 进球·比分·半全场·混合`；**混合串把各腿玩法写在腿旁边**。  
2. 【今日票面】非空仓时：优先写清每腿 `玩法=`；**预算=8元|12元**（听亲爱的；未指定可给两档对照）。  
3. 一腿未开售 → **只替该腿**换已开售玩法。  
4. 深热主胜（SP≤1.50）进胜平负串须标明风险；默认可改用让球腿。  
5. 比分/半全场进**串**默认偏博；稳单优先让球/胜平负/进球。

### λ 比分校准（V17.4.46 · 亲爱的「调」）

### 排除三件套（V17.4.31 · 2026-09-17 · 勇气版 · 005/利雅课 · **假热闸 V17.4.52**）

**不是弃权闸、不扩「不定」。** 场场仍必须 `排除=` 一个方向（或 `暂缓`）。准度靠信号排序，不靠少排除。

| 层级 | 看什么 | 作用 |
|------|--------|------|
| **① 情报（硬标准）** | 伤停、轮换、状态评分、战意、客场连败、**打法克制**、**阵容/板凳深度** | 决定谁最不可能 |
| **② 盘口/水位（质疑）** | 亚盘深浅、初终异动、竞彩↔亚盘背离 | 名气低赔可打成「假热」而**削弱锁热侧** |
| **③ 竞彩 SP（参考）** | 谁贵谁冷 | 只定基准；**禁止单独否决/单独决定排除** |

**硬规则**：
1. `排除=主胜` 或 `排除=客胜` 时，`理由=` 须含 ≥1 条硬情报短词（伤停/轮换/状态/战意/连败/克制/板凳/阵容/留力/分心/高原/深度/保级…），**或** 同行写 `质疑=`（背离/撤热/异动/假热/亚盘/水位）。
2. **禁止**仅用软词排胜负边：主场优势、经验、名气、抵消、纸面实力（无具体伤停/连败/克制等）。
3. SP 低 / 名气大 **不得免死**；①硬 + ②质疑成立 → **允许排假热**（利雅课：排的是**热侧**，不是冷侧）。
4. **禁止**靠扩大「不定/观望」刷排除仓命中率。
5. `排除=平` 不强制硬情报词（可贴脸/闷平），但仍禁止空理由。
6. **（V17.4.52 假热闸）** `质疑=` 含「假热」时：假热只削弱**热侧锁\***，**禁止**据此排除**冷侧**（保不败），除非 `理由=` 另有硬情报词。  
   - 例：`质疑=主热假热` → 不得仅凭此 `排除=客胜`；可降锁主→主不败/观望，或有硬情报再排客。  
   - `质疑=客热假热` → 不得仅凭此 `排除=主胜`。  
   - 只写「假热」未标主/客热 → 排胜负边仍须硬情报词（假热不得单独当排除凭证）。

**固定行（日闸 `EXCLUDE_INTEL_DAY=2026-09-17`；假热闸 `JUDGE_FIX_DAY=2026-09-22`）**：
```text
排除=<主胜|平|客胜>｜理由=<硬情报≤15字>｜质疑=<盘口≤10字|无>
```
`质疑=无` 可写；排胜负边时若无硬词且无质疑 → lint ERROR。假热+排冷侧无硬词 → lint ERROR。

**来源**：09-17 RMA 005 拉科软排客胜；利雅胜利名气低赔假热；亲爱的定层级「情报硬 / 盘口质疑 / SP 参考」；09-22 韩沙课（假热质疑反装正排冷侧）。

### 新增：情报质量档（ICS · V17.4.51 改档不改假精确分）

每场认真拆输出前必须给 **情报档**（观察骨架可一行带过）：

| 情报档 | 约当旧 ICS | 动作 |
|--------|------------|------|
| **充足** | ≥70 且伤停非未知 | PROCEED |
| **偏薄** | 50–69 **或** 伤停未知 | CAUTION（须补槽或接受封顶） |
| **不足** | <50 | STOP 深度叙事；有初盘类型+现盘仍交方向 |

写法（禁装精确到个位的假科学分）：
```text
情报档=充足|偏薄|不足｜动作=PROCEED|CAUTION|STOP｜伤停=有源|未知｜一句≤15字
（兼容旧稿 ICS≈70｜PROCEED；新稿优先情报档=）
```

槽位自检仍可心里过：积分/近5/伤停/H2H/战意/赛程——**不必**输出 15+15+25… 伪精确加总。

**不足**: STOP **深度叙事**（不进 TOP、不写满情报叙事）——**但**若已录 **初盘类型 + 现盘**，仍须交方向原子（可走 4.39 **A**）；**禁止**把不足当成「自动 B / 放弃方向」。
