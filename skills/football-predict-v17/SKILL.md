0. 多场先读 `防偷懒.md`；文首点名 `交卷模式=`。
0b. **（V17.4.71 · 下注单）先选场**：全表每场 ≤3 行粗筛 → 写 **【票面候选】**（≤3 编号 + 剔因）→ **认真拆集合=候选**（可写 `认真拆=票面候选`）。研究板可写 `【票面候选】无｜研究板`。

1b. **（V17.4.72）写 `01a-认真拆-NNN.md`**：每候选必含【近况比分表】【赛程前后】【排除因果】【反剧本因果】；01 同场节末链 `过程=`。
2. 【情报叙事】→【球队画像】→【比赛剧本】：排除（可暂缓）→ 剩余 → 二次 → 方向 → 倾向 → 净胜档 → 比分（按交卷模式）→ 进球。可先看结构盘；钉向后写【方向冻结】。过程展开优先写进 01a，01 保留结论槽供 lint。
3. 过【专闸触发表】；命中则按详表动作改方向/星级/TOP。
4. 扫盘：`初盘=真开盘|竞彩现盘|缺` + 现 SP/让球；认真拆且可介入才跑 λ/Edge/V15.6。

## 一、交卷模式与分诊

| 模式 | 第一读者问题 | 主交卷 | 票面 | 方向 |
|------|--------------|--------|------|------|
| **研究板** | 方向/比分/扫盘怎么看？ | 【全场汇总表】+ 扫盘 | 仍必有；**空仓默认合格**（写弃因） | 可 `观望/不定罩` 或 `不败｜弱置信=是` |
| **下注单** | 今天小票买什么 / 为何空仓？ | 【今日票面】可买腿 | **主 KPI=票中** | 必须锁\*/不败（禁观望充腿） |

```text
交卷模式=研究板｜或｜下注单
```
亲爱的未点名：说「给分/扫盘/不推票」→ 研究板；说「最少二串一/推票」→ 下注单。复盘「调中了没」：下注单=票中；研究板空仓日=方向仓+比分仓，空仓不算 FAIL。

**全表分诊**（禁止 N 场同等长文；**下注单硬序=先候选后深挖**）：

| 池 | 上限 | 篇幅 |
|----|------|------|
| 粗筛（选场） | 全表 | 每场 ≤3 行：能否锁\*/让侧、伤停硬词有无、是否薄客不败；写出进/剔 |
| 【票面候选】 | **≤3** | 文首必亮编号列表 + `剔=`；无合格场写 `无｜弃因=` |
| 重点认真拆 | **=候选**（≤3） | 01：取证摘要+必采+质量层+叙事+画像+情景+扫盘+冷门预防+方向冻结（+λ校准）+`过程=01a-…`；**过程加厚写 01a**（比分表/赛程/排除·反剧本因果） |
| 观察骨架 | 非候选 | ≤6 行/场；**禁止**事后升进票面（除非改候选并补认真拆）；**不写 01a** |
| 票面池 | 0～若干腿 | **腿 ⊆ 候选**；研究板可空；真下才临场核 XI |

认真拆 >3 须砍或写明破例（亲爱的点名）。认真拆 ≠ 候选 → lint ERROR（V17.4.71）。

```text
【票面候选】≤3｜005｜015｜020｜剔=其余观望/只能不败无让侧/伤停槽弱
分诊：认真拆=票面候选
```

**粗筛过闸（进候选）**：须像能锁\*或钉让侧；伤停/战意有硬词；非「客不败挡主场」无收据的薄叙事；玩法能结算且账本够（只能胜+平才罩 → 不进稳候选）。缺一条 → 剔。

**票面候选升档（V17.4.67，被 4.71 收紧）**：拟进票场 **必须已在【票面候选】且已认真拆**。`分诊弃锁=` 只允许标「曾想进票但未升」的弃因，**禁止**用弃锁把骨架场写进稳/博腿。

## 二、取证与情报

### 自研纪律（硬）

方向与票面只由本框架自研；第三方「结论产品」不进证据链。
- **禁**：荐单/计划单/连红专家/高手推荐/捷报猫/站点 AI/雷速荐单/聊天室/自媒体；口头禁报「某专家也看这方向」；`SOURCE_URL` 禁写荐单页。
- **捷报（V17.4.74 唯一取证源）**：`cp.nowscore.com` 列表抄「荐」后 SPF/让球 → 点「析」或 `MatchDetail/{id}cn.html` / `detail/{id}cn.html`。必扫：数据分析（近况·交锋·缺阵）→ 现场分析/detail（技统·进失球概率·走势）→ 三合一 → 胜平负。标题队名对不上 → 重进。
- **雷速 / 体彩官网**：认真拆**均不再必采**；禁 `SOURCE=体彩|雷速` 或开 sporttery/leisu 凑页。
- 网页一律 ego。URL 表与页签细则见 `references/取证速查.md`。

### 【认真拆必采】（认真拆必写 · 取证后排除前 · 缺行 lint WARN）

```text
【认真拆必采】伤停=有源|未见|槽弱｜机会代理=<技统进失/被射/角球一句|已查捷报无xG>｜初盘=真开盘|竞彩现盘|缺
```
未打开捷报现场分析禁写 `未见`；初盘词须与扫盘/即时走势同词。

### 情报档 · 伤停未知封顶

```text
情报档=充足|偏薄|不足｜动作=PROCEED|CAUTION|STOP｜伤停=有源|未知｜一句≤15字
```
- 伤停未知/未见/槽弱 → 最高 **偏薄/CAUTION**；禁 PROCEED；研究星封顶 ★★★☆☆；不进票面 TOP1。
- **偏薄不是结案章（V17.4.67）**：拟锁\*或拟进票 → **先补采**（捷报 MatchDetail 全序，尤其现场分析）再二次；补采后仍薄 → 写 `情报档=偏薄｜补采=已做｜仍不锁=…`。骨架分诊停写可以，须标分诊，禁用两年旧 H2H/「刚负强队」单独挡锁。
- **不足** → 停深度叙事、不进 TOP；但有初盘类型+现盘仍须交方向（可走深让 A）；禁「不足=自动放弃方向」。
- 禁写假精确 ICS 分（旧稿 `ICS≈70` 仍认）。红旗措辞（"绝对""复仇必胜"等）lint 会扫，触发须重写段落（清单见详表）。

### 【主菜质量层】（认真拆必写 · 四槽可 `缺` 禁编）

```text
【主菜质量层】
机会质量=<xG一句 | 场均进失+射正/大机会代理 | 缺>
风格对位=<压迫/出球/转换半句 | 缺>
赛程·轮换=<双赛/轮换风险一句 | 缺｜…>
比赛状态=<领先收缩/落后乱轰 · 服务进球比分 | 缺>
```
1. 捷报现场分析/数据分析缺数才写 `缺`；禁编 xG/PPDA；禁把 PPDA/肋部等写成必填假精确表；**禁回头开雷速凑数**。
2. 杯赛/欧战揭幕/该项首秀：`赛程·轮换=` 须含 `轮换|揭幕|双赛|负荷`（未知写 `缺｜杯赛轮换未核`）。
3. 质量层与 WDL 背离须在叙事点名；四槽全缺仍拟锁\*+★★★★ → 降不败/降星或补源。质量层不替代伤停闸。

### H2H 与外推

```text
H2H=正式|友谊|混｜近N=…｜权重=正式优先
```
友谊/热身只作风格参考，不得单独焊锁\*或定排除。联赛形态（进球荒/连胜连败）**不得直接外推**欧战/杯赛揭幕：看队伍重心（保级分心轮换 / 欧战底蕴 / 新军战意超常）。

### 【杯赛揭幕闸】（P0）

触发：认真拆且 `杯|锦标赛|英锦|足总杯|联赛杯|社区盾|超级杯` 且揭幕/首秀/小组第 1 轮。

- **下注单**：仍须锁\*/不败，但禁进票面 TOP1、星封顶 ★★★☆☆、倾向优先不定。
- **比分**：伤停未知或情报档偏薄/不足 → **强制比分弃权**（进球必出）；禁「弱置信+三格闷平篮」充好看。有 λ/射正代理且情报非不足才可弱置信装箱，防/旁须挂一格净胜≥2 或总球≥4。

## 三、剧本：排除 → 方向 → 倾向

### 情报定方向硬闸（V17.4.69 · 亲爱的点名）

**定什么只许看情报**：`排除` / `剩余` / `二次` / 方向原子（锁\*·不败） / `单子倾向` / 聊天与【今日票面】里的「稳腿」。硬情报＝伤停、轮换、状态、战意、连败、克制、板凳、赛程负荷、交锋正式样本等（同排除三件套①）。

**赔率 / SP 允许干什么（白名单，禁越权）**：
| 用途 | 可以 | 不可以 |
|------|------|--------|
| 专闸触发阈值 | 低结构贴脸、深让 SP≤1.35、深盘陷阱 SP 阈值 | 用阈值本身当排除理由或锁\*依据 |
| 盘口质疑辅证 | 亚盘异动/背离写进 `质疑=`，削弱锁热侧 | 无①硬情报时单靠质疑排胜负边定方向 |
| 出票算术 | Edge、串关到手、过 N 倍赔付 | 「赔率低所以稳」「SP 热所以锁」 |
| 复盘账本 | 买热门基准、Brier、隐含概率对照 | 用热门命中率倒逼改下一场方向 |

**硬禁**（口头/稿内同罪）：
1. 「SP≤1.50 / 1.3 / 1.4 所以稳」「热门低赔当胆」。
2. 排除行或二次行用「主胜 SP 低/客胜贵/赔率支持」当主因。
3. 【深让可锁】`依据=` 只写盘口/水位、无硬情报词 → 视为无 A 收据（须走 B 降维或不锁）。
4. 聊天给票把「稳」写成低赔串；要过 2 倍须明说「提高赔付≠提高命中」，腿仍须情报 PROCEED。

### 排除三件套（硬）

| 层 | 看什么 | 作用 |
|----|--------|------|
| ① 情报（硬） | 伤停、轮换、状态评分、战意、连败、克制、板凳深度 | **唯一决定**谁最不可能；定排除/方向 |
| ② 盘口/水位（质疑） | 亚盘深浅、初终异动、竞彩↔亚盘背离 | 辅证：可把名气低赔打成「假热」**削弱锁热侧**；不得单独定方向 |
| ③ 竞彩 SP（参考） | 谁贵谁冷 | 只定买热门基准与闸门阈值；**禁单独、禁主导**决定排除/方向/稳 |

```text
排除=<主胜|平|客胜|暂缓>｜理由=<硬情报≤15字>｜质疑=<盘口≤10字|无>
剩余={…}｜二次=倾斜…→锁* 或 分不清→不败｜单子腿=
```
1. 排胜负边：`理由=` 须含硬情报词；`质疑=` 只作辅证。禁仅用主场优势/经验/名气/纸面实力等软词。无硬词 → lint ERROR（**日夹 ≥2026-10-12**：有质疑无硬词仍 ERROR，V17.4.69）。
2. SP 低/名气大不免死；排假热须①硬情报成立，②质疑只削弱锁\*、不单独排边。
3. **假热闸**：`质疑=假热` 只削弱热侧锁\*，禁据此排**冷侧**（除非另有硬情报词）→ lint ERROR。
4. `排除=平` 可贴脸/闷平，仍禁空理由；禁靠扩大「不定/观望」刷排除仓。
5. **暂缓**：仅当 `情报档=偏薄|不足` 或揭幕首秀或关键槽<2；理由写 `情报档偏薄|不足|揭幕|槽不足`（禁写「ICS低」）；暂缓后禁用软词补砍充排除仓；有硬情报后补砍并写修订。汇总表排除列写 `暂缓`。
6. **逆热门排除旁注（观察计数 · 未满进化闸账本 30 前不升硬闸）**：若排除的是胜平负 SP 最低一侧，理由旁加 `逆热门排除`（方便复盘计数）；方向仍须①硬情报自洽，禁用「逆热门」本身当理由。

### 活络默认（V17.4.67 · 执行硬口径 · 09-29/30 复盘）

假热 / 薄档 / 让脏 **分闸**，禁捆成「全场不定、整张怂」：

| 信号 | 允许 | 禁止 |
|------|------|------|
| 假热（极热 SP/支持） | 削弱锁\*；**不进默认稳串**；实力账仍可写 **倾向=主胜/客胜** | 用「刚负强队」一棒子打死倾向；假热单独排冷侧 |
| 让球脏（让平热/三向散/-1 穿盘味） | 汇总表 **让球胜平负=让平(盘口)** 或让平｜弱；可作 **博腿** | 用让脏挡 SPF 锁\*；让球列留「不定」糊过去 |
| 二次=倾斜… | **锁\*** + 倾向=所锁格 | 二次已倾斜却交不败（执行缩手） |
| 二次=分不清 | 不败；可加 `权重印象=主>平≫客`（非校准%） | 用假 % 三格冒充实锤 |
| 博腿（4元） | 比分/总球/半全场/让平须 **尖、有赔率弹性**；进球区间与复式对齐（深胜可盖 4） | 研究弱置信 → 博空仓或写成第二个稳 |

口头交卷：下注日 **先报票腿**，再报方向率。

### 方向原子

| 模式 | 允许 |
|------|------|
| 下注单 | 只写其一：`锁主/锁客/锁平/主不败/客不败`（单选可写主胜/客胜/平局=锁） |
| 研究板 | 上列；或 `方向=观望` / `方向=不定罩`（仍给进球+扫盘）；或 `主不败|客不败｜弱置信=是` |

- 允许集：锁主={主胜}；锁客={客胜}；锁平={平}；主不败={主胜,平}；客不败={客胜,平}；观望=∅（不计方向 miss）。
- **禁胶着、禁空槽、禁方向空着。** 观望 ≠ 胶着（观望是显式 pass，不进票面腿；汇总表写 `观望`、倾向 `不定`）。
- 研究板偏薄/伤停未知：默认暂缓排除 + 观望/弱置信不败；禁硬砍冷侧充排除仓。
- **锁平许可证**：须含 0-0 或 `闷平/TRUE_00/死盒/焊平` 句面；犹豫不是平。

### 单子倾向

因果硬：**允许集 → 倾向 → 再装箱**；禁用主推比分 1X2 倒推倾向。
- 倾向 ∈ 允许集（主不败禁倾向客胜；客不败禁倾向主胜）；分不清写 `不定`。
- 锁\*场汇总表倾向列必填所锁格。
- `02` 先写方向行，下一句才写单子腿；禁把倾向写成锁主/锁客/锁平。

### 二次确认（方向原子前必过）

认真拆场（及票面候选升档场）在定方向原子前须写一行：`二次=分不清｜排除后仍平` / `二次=倾斜主胜｜…` / `二次=倾斜客胜｜…` / `二次=倾斜平｜…`。禁跳过；禁用「ICSxxx」代替。

- **二次=倾斜主胜/客胜/平** → 须出对应 **锁\***；禁退写成不败（执行缩手）→ lint ERROR。
- **二次=分不清** → 不败即可；可写 `权重印象=主>平≫客`（定性，非假精确 %）。
- 假热可挡锁\*，**不得**把二次从倾斜改成「假热所以不定倾向」。

### 深让警示与可锁单选（A/B）

**深让 ≠ 自动不败。** 不败留给贴脸/分不清/真双选。
警示触发（不自动改方向）：让球 ≤ -1.5 或 热门 SP ≤ 1.35，且拟锁该侧。

| 分支 | 条件 | 方向 | 须写 |
|------|------|------|------|
| **A 可锁** | **须**情报够（档差/战意/伤停有源等硬词）；结构盘+现盘同向只作辅证，**不得**单独开 A（V17.4.69） | 锁\* | 【深让可锁】收据（`依据=` 含硬情报词）；倾向=所锁格；屠杀场防/旁挂屠杀格 |
| **B 降不败** | 缺硬情报、或水位撤热/背离/贴脸摇摆、或盘口与锁侧明显矛盾 | 不败 | `【深让降维】触发=是｜理由=…` |

```text
（真开盘）【深让可锁】触发=是｜初盘=真开盘｜水位=稳|撤热…｜现盘=…｜依据=情报|盘口｜一句≤20字
```

## 四、比分与进球

**硬序（禁颠倒）**：方向 → 倾向 → 净胜档（闷平/小胜/中胜/大胜）→ 有把握才主/次/防 → 进球区间由主+次总球反推（无比分时进球仍必出）。比分是情景装箱，不是 SP 公式吐分。

| 格 | 装什么 |
|----|--------|
| 主 | 最像终场；∈允许集；有优势须胜负球（禁用 1-1 当锁向安全垫） |
| 次 | 同族次高频；倾向已定则主次同族 |
| 防 | 倾向已定 → 允许集另一向（不败常防平）；不定 → 权重 Top3 且须含平；收据过闸可挂 ±1 反方向 |

| 交卷模式 | 比分 |
|----------|------|
| 研究板 + 情报充足且伤停有源 | 默认给主/次/防（没把握仍可弃权） |
| 研究板 + 伤停未知/偏薄/不足 | 默认弃权；点名「要好看」才装箱并写 `弱置信=是`（揭幕闸场不可绕过） |

## 五、佐料（初盘诚实）与出票闸

| 初盘类型（扫盘行必选一） | 水位怎么写 |
|--------------------------|------------|
| `初盘=真开盘` | 初→现路径可写撤热/灌热/背离 |
| `初盘=竞彩现盘` | 只写「竞彩现盘对照」；禁假装亚欧开盘路径 |
| `初盘=缺` | 水位写 `缺`；禁可介入；研究板仍可给方向 |

2. 竞彩支持率=民意辅证，不得单独焊锁\*或定排除。
3. 佐料默认不改方向；**否证回流**（水位/现盘相对已冻方向剧烈背离、λ′ 严重打架、临场伤停爆出）→ 回流重判并写 `对照盘口修订=`。
4. 双闸门（仅出票）：胜平负 Edge_eff ≥1%；让球/进球 ≥3%（≥5% 可标高赔单关主推）。Edge_Refine/MKT_CONFLICT 只改【出票】提示。降维方向与结果预测打架 → 出票观望。
5. V15.6 五补丁仅认真拆且出票可介入场扫（其余写 `触发=跳过｜池=观察`）；命中 Zombie 须写「⚠️ 深盘陷阱预警」。
6. **Edge 诚实**：体彩抽水厚，多数场 Edge 为负属正常 → 出票观望，但仍交方向+进球（比分有把握才交）。

## 七、文末：汇总表 · 票面 · TOP · 让球稳健

### 【全场汇总表】（必出 · 研究板主交卷 · 回话同列）

| 编号 | 对阵 | 排除 | 推方向 | 倾向 | 让球胜平负 | 比分 | 进球 | 强制 |
