# 足球框架 · 使用说明

版本：**分析优先版**。默认研究 5 场，只走「选场 → 核心情报 → 比赛分析 → 概率预测 → 实际 SP/EV → 票面」。细则以 `SKILL.md` 为准。

## 安装

### Skills CLI

```bash
npx skills add yuansql/FootballPredictions --skill football-predict-v17
```

### Git 克隆

```bash
git clone https://github.com/yuansql/FootballPredictions.git
cd FootballPredictions
bash scripts/sync-skill-bundle.sh
```

### OpenSkills

```bash
openskills install yuansql/FootballPredictions
```

### 千问 / DeepSeek 等外部模型

粘贴 `SKILL.md`、`output-template.md`；需要手算概率时再贴 `references/p_model手算.txt`。不再要求启动卡、联赛插件和过程稿模板。

## 直接使用

对 Agent 说：

```text
研究今天竞彩，默认5场，预算100元。
```

或指定比赛：

```text
分析这5场：……；只研究胜平负和让球，预算100元。
```

Skill 本身不抓网、不买票。宿主需要能获取可靠赛果、阵容伤停和实际可买 SP；来源与时间直接写进分析正文即可。

## 交卷要求

- 主要篇幅用于近况、主客、伤停、赛程、攻防对位、比赛剧本和反证。
- λ 有依据，所有玩法共用同一动态泊松矩阵。
- 保守 P 运行 `scripts/conservative_probability.py`，不手填。
- 只采拟研究玩法的实际 SP，计算真实 EV 与保守 EV。
- 整票保守 EV>0 才出票，否则空仓；研究 5 场不等于必须买 5 场。
- 不再强制 01a、`_raw/`、证据/票面/冻结 JSON、lint、审计、赛前账本或汇总表。

## 维护

修改 `SKILL.md`、`output-template.md`、`防偷懒.md`、`使用.md`、`references/` 或 `rules/` 后：

```bash
# 只同步仓内 skill 包
bash scripts/sync-skill-bundle.sh --no-local

# 需要同时更新本机 Cursor/Agents 时
bash scripts/sync-skill-bundle.sh
```
