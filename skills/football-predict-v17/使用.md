## 下载 / 安装后：配合什么用

Skill **本身不抓网、不买票**——它只约束 Agent 怎么取证、怎么写 `01`/`01a`、怎么出票。装完后要配齐下面几样，才能按 V17.4.79 跑通。

### 1. 宿主（必有其一）

| 宿主 | 怎么装 | 怎么唤起 |
|------|--------|----------|
| **Cursor**（推荐） | `npx skills add yuansql/FootballPredictions --skill football-predict-v17` → 落到 `~/.cursor/skills/football-predict-v17/` | 聊天里说「今天竞彩 / 分析周五板 / 复盘」即可；Agent 应亮牌读 `SKILL.md` |
| **Claude Code / Agents** | 同上或 sync 到 `~/.agents/skills/football-predict-v17/` | 同左 |
| **千问 / DeepSeek 等** | 不装 skill 包；按联赛**分贴**启动卡+主控+1 插件+手算+人设 | 见下文「别人怎么用 · C」 |

### 2. 日稿目录（落盘约定）

| 用途 | 路径 / 文件 |
|------|-------------|
| 比赛日夹 | `YYYY-MM-DD/`（例：亲爱的工作区 `@数据/2026-10-16/`） |
| 结论权威 | `01-竞彩分析.md` |
| 候选过程 | 每候选一份 `01a-认真拆-NNN.md` |
| 原文证据 | `_raw/`（analysisJs / detail / 列表摘录必留） |
| 复盘 | `03` / 对账 `04` |

不要把框架源文件复制进日夹；执行仍读 skill 目录。

### 3. 取证工具链（V17.4.78 · 和 skill 配套）

| 优先级 | 工具 / 动作 | 采什么 | 备注 |
|--------|-------------|--------|------|
| **1** | **直接请求**（curl / fetch / 本机 HTTP） | `live.nowscore.com/analysisJs/data{id}.js`、`detail/{id}cn.html` | 近况/积分/交锋/技统；**落盘 `_raw/`** |
| **2** | **ego-browser**（或等价已登录浏览器自动化） | `cp.nowscore.com` 竞彩列表「荐」后 **SPF 数字**；教练/裁判/捷报猫 | 列表格多为 JS 填，纯 HTML 常是 `-` |
| **兜底** | REA / 浏览器开 analysis HTML | 接口失败或要整页证据时 | 不能代替 analysisJs 落盘装「已取证」 |
| **禁** | 体彩官网 `sporttery.cn`、雷速必采、荐单/AI/连红页 | — | 焊锁\* 一律禁止 |

细则与 URL 表：`references/取证速查.md`。

### 4. 交卷校验（必跑）

```bash
python3 ~/.cursor/skills/football-predict-v17/scripts/lint_draft.py \
  /path/to/YYYY-MM-DD/01-竞彩分析.md
```

源仓内也可：`python3 scripts/lint_draft.py <日夹>/01-竞彩分析.md`。  
未过 lint（ERROR）不得宣称完成。

### 5. 不需要额外配的

- **不需要**体彩官网账号、雷速会员、荐单站。  
- **不需要**把本仓库再复制一份进日夹。  
- Edge / λ / V15.6：仅认真拆且「出票可介入」时按 SKILL 再开 `p_model手算` + `rules/V15.6`。

### 最小可跑清单（打勾用）

- [ ] 宿主已装 `football-predict-v17`（或分贴精简包）  
- [ ] 有日夹可写 `01` / `01a` / `_raw/`  
- [ ] 能直接请求 nowscore 的 `analysisJs` + `detail`  
- [ ] 有 ego（或能渲染列表）抄竞彩 SPF  
- [ ] 交卷前能跑 `lint_draft.py`

## `scripts/sync-skill-bundle.sh`

**作用：维护用同步脚本，不是预测脚本。**

改完 `references/` / `SKILL.md` / `output-template.md` / `防偷懒.md` / `使用.md` / `rules/` 后**必须跑**：

```bash
bash scripts/sync-skill-bundle.sh
# 仅更新仓库 skills/ 副本、不动本机 Cursor：
bash scripts/sync-skill-bundle.sh --no-local
```

会同步到：

- 仓库 `skills/football-predict-v17/`
- 仓库 `.cursor/skills/football-predict-v17/`
- 本机 `~/.cursor/skills/football-predict-v17/`
- 本机 `~/.agents/skills/football-predict-v17/`

其中 **`使用.md` 会进 skill 包**（与 SKILL 同级）。`README.md` 仍只留仓库根、不进 skill。

### 什么时候必须跑

- 改了任意框架正文 / skill / 模板 / 本使用说明  
- 准备 `git push` 给别人用之前  
- **本机 Cursor 要用最新规则时**

### 卸载本机 skill

```bash
rm -rf ~/.cursor/skills/football-predict-v17
rm -rf ~/.agents/skills/football-predict-v17
rm -rf .cursor/skills/football-predict-v17
```

## 别人怎么用

### A. Skills CLI（推荐）

```bash
npx skills add yuansql/FootballPredictions --skill football-predict-v17
```

装完先打开 skill 包里的 **`使用.md`（本文件）**，按「下载后配合什么用」配日夹 + 直接请求 + ego + lint。

### B. Git 克隆

```bash
git clone https://github.com/yuansql/FootballPredictions.git
cd FootballPredictions
bash scripts/sync-skill-bundle.sh   # 装到本机 Cursor/Agents
```

### C. 千问 / DeepSeek（精简分贴）

按联赛只上传/粘贴：启动卡 + 主控 + **一个**插件 + p_model + 人设。  
激活句示例：

```text
【系统】先遵守《外部模型启动卡》，只使用已贴文件。
本场：瑞超 → 已贴主控/小联赛/手算/人设。
体彩默认。对阵：___ vs ___
必须：取证→情报→球队→剧本→硬闸→结果预测→出票。
```

| 联赛 | 插件 |
|------|------|
| 挪超/芬超/瑞超等 | 小联赛 |
| 英超等五大 | 五大联赛 |
| 世界杯 | 世界杯 |

> 分贴模式**没有**自动 lint / 自动落盘；取证仍建议自备 analysisJs+detail 原文。

### D. OpenSkills

```bash
openskills install yuansql/FootballPredictions
```

## 预测时硬要求（摘要）

1. **INTEL_FIRST**：取证 → 情报 → 球队 → 剧本；盘口只做出票辅助；方向禁只靠 SP  
2. **先选场**：下注单先【票面候选】≤3，再认真拆；票腿 ∈ 候选  
3. **取证通道**：analysisJs+detail **直接请求落盘**；ego 补 SPF；不开体彩/雷速  
4. **双轨**：【研究推荐】场场有方向+进球（比分可弃权）；【出票】可全观望  
5. **排除三步**：`排除=` → `剩余=` → `二次=倾斜→锁*` 或 `分不清→不败`  
6. **默认票面**（V17.4.94/4.91/4.90/4.84）：每天 12 元=稳+博，玩法不限须落地（不败进稳→胜/平；让平只进博）；每张≥2场（禁单关）；每条命中路返还≥2倍本金（V17.4.85）  
7. 未写「北单」→ 竞彩（文首【频道】可写「体彩」仅表玩法频道）

细则见 `SKILL.md`。
