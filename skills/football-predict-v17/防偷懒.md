# 全表 / 多场防偷懒（V18 · 与 `SKILL.md` 同口径）

先分诊、再取证、后建模。候选数量用于控制研究成本，不用于提前决定谁进票；空仓是合法交付，流程全绿不代表预测准确或盈利。

## 默认纪律

- **先选场**：文首写 `交卷模式=研究板|下注单` 与【票面候选】（通常≤4，研究板可无）→ 只认真拆候选；票腿必须来自候选。不得因未开售、赔率不漂亮或串关返还失败提前剔候选。
- **过程落盘**：每个候选另写 `01a-认真拆-NNN.md`，至少含【近况比分表】【赛程前后】【排除因果】【反剧本因果】【三页取证】；01 节末写 `过程=01a-认真拆-NNN.md`。01 是结论权威，01a 不另开方向。
- **证据优先**：analysisJs、detail、竞彩列表及教练/裁判/捷报猫按 `references/取证速查.md` 落盘；官方、伤停和 xG 等外部源用于补槽与交叉核对。荐单、AI 结论、专家连红和聊天室不得入证。
- **先冻方向**：EV 前写【方向冻结】。新信息可修订，但必须写具体原因；不得因 EV 不好看改球队故事。
- **同一概率源**：每场用同一动态截断比分矩阵派生胜平负、让球、总进球和比分；缺可靠分布就写未估/弃权。
- **保守P 不手填**：写 `λ区间=H[lo,hi]/A[lo,hi]` 与 `区间依据=`，再用 `scripts/conservative_probability.py` 角点法导出 `保守P`。lint 会重算比对，不一致即 ERROR；不得为过闸收窄区间，也不得为显得稳健放宽区间。
- **真实 EV**：每个实际购买选项写实际 SP、`p_model`、`p_conservative`、`p_be`、EV 与保守 EV。非空仓须核心数据足够且整票保守 EV>0。多腿票写 `rho`，账本标定前一律 `未标定`。
- **账本落盘**：赛前冻结后追加 `pred-ledger.csv`／`tickets-ledger.csv`，赛后跑 `scripts/score_ledger.py`。没有账本就没有校准证据，不得宣称“概率已校准”或“保守P 偏保守/偏松”。
- **预算真实**：不设默认每日 12 元或固定稳/博金额；按用户预算、实际注数与倍数记账。不要求每条命中路翻倍，不用主客身份、让平名称或星级决定票面。
- **允许空仓**：数据不足、保守 EV≤0、预算或开售限制都可空仓。空仓写 `账本=未触发｜EV审计=未触发`，不得冒充已审计。

## 三池（不许混成一档）

| 池 | 哪些场 | 必须写出的内容 |
|---|---|---|
| 粗筛→【票面候选】 | 全表先过 | 文首候选编号与剔因；每场粗筛写可验证线索、主要未知和进/剔 |
| 观察骨架 | 非候选 | ≤6行：排除/剩余/方向/倾向/总球或弃权/现SP或缺/一句风险；事后进票先升候选并补过程 |
| 重点认真拆 | =票面候选 | 取证清单、情报叙事、球队画像、比赛剧本、方向冻结、λ与保守区间、统一矩阵、风险标记、01a链接 |
| 票面池 | 今日实际票腿，可为空 | 腿⊆候选；观望场禁票；每腿完整选项、SP与两种概率；整票本金、模型EV、保守EV与联合概率口径 |

认真拆集合不等于候选、候选缺 01a、非候选事后直接进票，均算未走完。研究板也必须交【今日票面】，可写空仓。

## 伤停与风险标签

- “已核”只认本场官方名单、赛前发布会、本场缺阵页或正式首发；上一场未首发只能标待证。
- 新缺/旧缺不是自动排边规则。写球员角色、替补差距、对位及影响是否已反映在样本中；机制不清就只降置信。
- 排主胜/客胜前写【强弱对位】：被排方强项、对方弱项、能否打得到；写不出机制不得为覆盖率先验排除。
- 低结构、深让、欧战、双新军、跨市场差异和 V15.6 名称只作风险/Shadow 标签，不自动改 λ、方向、比分、EV 或出票。
- 比分不强制三格，不强制净胜≥3；总球不强制数字区间。方向可研究，比分和总球可分别弃权。

## 标题（给 lint 看的）

```text
## 周四004 贝蒂斯 vs 赫塔费
```

- 小写 `vs`；编号为 `周`+一二三四五六日+三位数字。

## 交卷闸

1. 文首有 `交卷模式=研究板|下注单` 与【票面候选】。
2. 候选认真拆、01a、证据和赛前冻结字段齐全。
3. 每个票腿来自候选，完整列出所有购买选项与概率。
4. 非空仓有 `账本=过｜EV审计=过`；空仓写未触发。
5. 运行：

```bash
python3 scripts/lint_draft.py <日夹>/01-竞彩分析.md --day YYYY-MM-DD
python3 scripts/check_day.py <日夹>
```

6. lint 或审计有 ERROR 不得宣称完成；0 场全绿同样不是有效交卷。

## 不默认执行的旧动作

- 不运行 V15.6 概率乘数、Force_Output 或 Score_Override。
- 不执行固定 RAW 折扣、统一 1%/3% 概率差闸、固定翻倍、让平禁稳、客热第二腿禁稳或低结构共胆限制。
- 不为凑票强制胜平负“降维”到让球/总球，不强制单关或复式。
- `/test-product-manager`、`/test-engineer`、`/test-ui-reviewer` 不用于足球分析。
