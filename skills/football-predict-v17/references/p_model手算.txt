# p_model 手算步骤（锁定 · 独立泊松截断）

> 绑定：V13.3 / V17.4.9（含 V15.6 五补丁 · INTEL_FIRST · 双轨推荐）
> 用途：把「模型胜率 p_model」从可抄公式算出来，再算 Edge（含降维让球/总进球）。  
> p_model ≠ 赔率；是你用 λ 算出的概率。
> 补丁源码：`rules/V15.6_patches.py`；规范：`rules/V15.6_patches.txt`。

──────────────────────────────────────────────────────────────────────────────
■ 0. 一句话
──────────────────────────────────────────────────────────────────────────────
1) 先得到主队预期进球 λ_H、客队预期进球 λ_A（必须是一个数，不能是空白）  
2) 用泊松算出每个比分概率（进球 0～5 截断）  
3) 把「主赢 / 平 / 客赢」的比分概率分别加总 → P_H / P_D / P_A  
4) 框架方向对应的那一项 = **p_model**  
   （方向=主胜 → p_model=P_H；平局 → P_D；客胜 → P_A；胶着 → 不算 Edge）

算不出 λ 的点估计 → p_model 不存在 → **弃单**（禁止瞎编 55%）。

──────────────────────────────────────────────────────────────────────────────
■ 1. 先拿到 λ_H、λ_A（点估计）
──────────────────────────────────────────────────────────────────────────────
按联赛插件取数（细则见各文件），这里只要求落成两个小数：

| 场景 | λ 怎么来（摘要） | mode |
|------|------------------|------|
| 五大 / 有 npxG | 用框架 λ 合成（含 EPV 修正） | POINT |
| 小联赛无 npxG | 近5或赛季场均进球作底（RAW_GOALS），再加减伤停惩罚；见小联赛 §3.5 | POINT 或勉强 POINT |
| 只有区间 | 取中点：λ = (低+高)/2，旁注 RANGE | 可算 p_model，风险+1 |
| 完全估不出 | — | **弃单** |

主场加成：若数据是中性场均、未含主场，λ_H 可 ×1.05～1.10（写明用了多少）；已含主场样本则不再乘。

落表必须写：`λ_H=· · λ_A=· · mode=POINT|RANGE`

──────────────────────────────────────────────────────────────────────────────
■ 2. 单队进球概率（泊松）
──────────────────────────────────────────────────────────────────────────────
假设：主队进球数 X、客队进球数 Y 独立，且

```text
P(X = k) = e^(-λ_H) × (λ_H)^k / k!
P(Y = j) = e^(-λ_A) × (λ_A)^j / j!
```

k, j = 0,1,2,3,4,5（手算截断到 5；≥6 并入「稀有」，见下）

阶乘：0!=1, 1!=1, 2!=2, 3!=6, 4!=24, 5!=120  
e^(-λ) 可用计算器；常见值：

| λ   | e^(-λ) 约 |
|-----|-----------|
| 0.8 | 0.4493 |
| 1.0 | 0.3679 |
| 1.2 | 0.3012 |
| 1.4 | 0.2466 |
| 1.5 | 0.2231 |
| 1.6 | 0.2019 |
| 1.8 | 0.1653 |
| 2.0 | 0.1353 |

允许：Excel `POISSON.DIST(k, λ, FALSE)` 或任意泊松计算器——**公式必须同上面**，结果抄进表。

──────────────────────────────────────────────────────────────────────────────
■ 3. 比分概率表（6×6）
──────────────────────────────────────────────────────────────────────────────
```text
P(比分 k-j) = P(X=k) × P(Y=j)
```

画表（行=主队进球 0～5，列=客队进球 0～5），每格填乘积。

截断误差：只算到 5 会漏掉 6+ 球比分。手算补丁（二选一，写明用了哪个）：
- **简补**：把 P_H、P_D、P_A 三个和重新归一到 100%（乘法归一一次）  
- **或**：忽略（球荒局误差小）；高 λ（>2.2）建议用简补或扩到 0～6

──────────────────────────────────────────────────────────────────────────────
■ 4. 加总成三个结果概率
──────────────────────────────────────────────────────────────────────────────
```text
P_H = 所有 k > j 的格子之和     （主胜）
P_D = 所有 k = j 的格子之和     （平局）
P_A = 所有 k < j 的格子之和     （客胜）
```

若用了简补：`P_i ← P_i / (P_H+P_D+P_A)`

检查：三者之和应 ≈ 1.00（允许 ±0.02 的截断误差；简补后应为 1）。

──────────────────────────────────────────────────────────────────────────────
■ 5. 取出 p_model → 算 Edge
──────────────────────────────────────────────────────────────────────────────
```text
方向=主胜 → p_model = P_H
方向=平局 → p_model = P_D
方向=客胜 → p_model = P_A
方向=胶着 → 不算 Edge（N/A）

p_fair = 胜平负 SP 乘法去水后，同方向那一项
Edge_raw = p_model − p_fair
```

**分口径计算 + 双闸门（与主控 V17.4.6 对齐）：**
| λ 口径 | 计算 Edge_eff | 胜平负可介入 | 让球/进球可介入 |
|--------|---------------|--------------|------------------|
| Understat npxG 等可信 | Edge_eff = Edge_raw | ≥ **1%** | ≥ **3%**（≥5% 宜单关高推） |
| RAW_GOALS / NO_NPXG | ① λ'=0.65λ+0.35·LG_HALF 重算 p_model<br>② Edge_eff = Edge_raw×0.60（样本&lt;6场再×0.85） | ≥ **1%** | ≥ **3%**（≥5% 宜单关高推） |

另：Edge_raw≥12% 且方向与市场热门对打 → 无≥2条非λ证据则**弃单**（FALSE_EDGE_MKT_CONFLICT）。  
同轮 Tier3「客胜小胜+1或3」同构最多荐 **1** 场（TEMPLATE_STACK）。

泊松加总得到 P_H/D/A 后、算 Edge **之前**，必须跑 V15.6：
1. **Kryptonite**（客队近10交锋≥8胜）→ 拉偏 P_A 后归一化  
2. **Jinx**（主场近5交锋≥3平）→ P_D 平滑；若最高则平局首选  

落表一行示例：
`口径=RAW λ→λ' | P_H/D/A=… | p_model=… | p_fair=… | Edge_raw=+2% Edge_eff=+1.2% → 胜平负可介入(≥1%)`

──────────────────────────────────────────────────────────────────────────────
■ 5b. 降维：让球 / 总进球（同一张 0～5 比分表）
──────────────────────────────────────────────────────────────────────────────
> 对齐主控 [DIM_REDUCTION]。仅当胜平负 Edge_eff<1% 且未硬弃单时启用。

**让球胜平负（竞彩口径 · 主队让球线 L）**

记净胜 GD = 主队进球 − 客队进球。L 为竞彩「主队让球」数字：  
主让1 → L=−1；主让2 → L=−2；主受让1 → L=+1；平手 → L=0。

```text
让胜 = Σ P(比分) 对所有 GD > −L      （主队赢盘）
让平 = Σ P(比分) 对所有 GD = −L      （走盘/让平）
让负 = Σ P(比分) 对所有 GD < −L
```

例：主让1（L=−1）→ 让胜=GD≥2；让平=GD=1；让负=GD≤0。  
例：主受让+1（L=+1）→ 让胜=GD≥0（主胜或平）；让平=GD=−1；让负=GD≤−2。

取与【结果预测】同向的一项为 p_model_HC；三项 SP 乘法去水得 p_fair_HC；再算 Edge。

**总进球 T = X+Y**

```text
P(T=n) = Σ_{k+j=n} P(X=k)P(Y=j)   （k,j∈0..5，必要时归一）
```

- 竞彩勾选集合 S（如 {1,3}）→ p_model = Σ_{n∈S} P(T=n)  
- 大 2.5 → p_model = P(T≥3)；小 2.5 → P(T≤2)  
须有对应 SP 才能算 Edge；无 SP → 该通道跳过，不编利润。

RAW 口径：降维 Edge 同样先用 λ′ 表，再 Edge_eff=Edge_raw×0.60（小样本×0.85），子盘闸门 ≥3%。

若触发 **StarFactor**：子盘（让球/总进球）须用调后 λ 重算比分表；主盘 1X2 仍用未调 λ。  
若触发 **Zombie**：让球 Edge_eff = Edge_raw_HC × 0.60 × 0.65，并强制写深盘陷阱预警。

■ 5c. V15.6 补丁手算挂载点
──────────────────────────────────────────────────────────────────────────────
| 步骤 | 补丁 | 何时 | 公式摘要 |
|------|------|------|----------|
| 泊松前 | StarFactor | 客三强+后防伤≥2+中前场全勤+客胜赔≤1.50 | λ_A×1.15，λ_H×1.10（仅子盘） |
| 泊松后 | Kryptonite | 客近10交锋≥8胜 | offset=(r-0.5)×0.24；P_A×(1+offset)；归一 |
| 泊松后 | Jinx | 主场近5≥3平 | P_D=0.6·pois+0.4·hist；H/A×shrink |
| Edge后 | Zombie | 垫底2+胜≤1+L≥+1 | Edge_HC×0.60×0.65 |
| Edge后 | Edge_Refine | 主盘 Edge_eff≤-5% | 扫描平/冷门；≥3%锁定高赔 |

缺失触发数据 → 该补丁不触发（禁止臆造 H2H/排名）；仍须在【V15.6补丁】写「触发=无」或列出已触发项。

──────────────────────────────────────────────────────────────────────────────
■ 6. 手算示范（请按此格式自算）
──────────────────────────────────────────────────────────────────────────────
设 λ_H=1.5，λ_A=1.0（虚构）

主队 P(X=k)：
```text
P0=0.2231
P1=0.2231×1.5/1=0.3347
P2=0.3347×1.5/2=0.2510
P3=0.2510×1.5/3=0.1255
P4=0.1255×1.5/4=0.0471
P5=0.0471×1.5/5=0.0141
（可用递推：P(k)=P(k-1)×λ/k）
```

客队 P(Y=j)，λ=1.0：
```text
P0=0.3679  P1=0.3679  P2=0.1839  P3=0.0613  P4=0.0153  P5=0.0031
```

部分格子：
```text
0-0: 0.2231×0.3679≈0.0821
1-0: 0.3347×0.3679≈0.1231
2-0: 0.2510×0.3679≈0.0923
1-1: 0.3347×0.3679≈0.1231
0-1: 0.2231×0.3679≈0.0821
…
```

将全部 k>j / k=j / k<j 加总后（示范约值，你应自己加完）：
```text
P_H≈0.49  P_D≈0.26  P_A≈0.25  （截断后略归一）
若方向=主胜 → p_model≈49%
```

（完整加总以你的表格为准；本示范只展示算法，不替代你的求和。）

──────────────────────────────────────────────────────────────────────────────
■ 7. 与 Tier3「负二项」的关系（手算锁定）
──────────────────────────────────────────────────────────────────────────────
V17 写 Tier3 可用负二项——**手算 p_model 一律用本节独立泊松截断**，不再手算负二项。  
负二项只作为「风险更高」的提醒；λ 仍拿不到 → 弃单。

──────────────────────────────────────────────────────────────────────────────
■ 8. 自检清单（算 Edge 前勾）
──────────────────────────────────────────────────────────────────────────────
[ ] λ_H、λ_A 已写出且来源可追溯（npxG / RAW_GOALS / 中点）  
[ ] 已列出双方 0～5 的 P(k)  
[ ] 已填 6×6 或等价加总得到 P_H/P_D/P_A  
[ ] V15.6：Kryptonite/Jinx 已扫（或明确未触发）；StarFactor 子盘 λ 已区分  
[ ] p_model 与框架方向一致  
[ ] SP → p_fair（乘法去水）已算  
[ ] Edge_raw / Edge_eff 已写；口径已标 npxG 或 RAW_GOALS
[ ] RAW_GOALS 已做 λ→λ' 回归与 ×0.60 打折；胜平负闸≥1%、子盘闸≥3%
[ ] Zombie / Edge_Refine 已扫；触发则落地警示或冷门覆盖
[ ] 胜平负 Edge_eff<1% 时已按 §5b 算让球/总进球，或注明缺 SP 跳过降维

任一勾不上 → 本场 p_model/Edge 无效 → 弃单。
