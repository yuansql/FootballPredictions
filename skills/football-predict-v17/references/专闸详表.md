### 研究 TOP 软清单（V17.4.9+ · 2026-08-13 v2 · **V17.4.41 分席** · 非弃单硬闸）

排【今晚研究 TOP】前自检（**约束 TOP 席位/星级上沿；票面席另受 4.41「可买腿」约束；不改【比赛剧本】方向，不做出票弃单理由**）：

0. **（4.41）票面席**：须 `席=票面` + `买=` 可结算映射；不败且倾向不定 → **只能观察席**，禁止进票面席/票面 3/3。  
1. 主胜 SP≤**1.50** 且非λ证据几乎只有「主场/名气」→ 研究星级封顶 **★★★☆☆**，**默认不进 TOP2**（可进 TOP3 或降权区）。  
2. 杯赛/欧战**次回合**且一方首回已领先 → 「客不败/管理比赛」**不得默认满星进 TOP3**；须另有伤停/形态证据，否则降权或旁注。  
3. 德比 或 首回 **0-0** 定生死 → **默认降权出 TOP**（宁缺毋滥，勿硬凑满 3 席）。  
4. 杯赛/解放者杯/欧战资格 **首回合主场** → **默认不进 TOP1**；进 TOP2 须剧本**硬写防平**（1-1/0-0）。  
5. **刚大胜/屠杀**后短期复赛（近 1 场净胜≥4 或公开屠杀叙事）→ **不满星 TOP1**（可旁注/降权）。  
6. 欧战/杯赛拟进 TOP 前须显式 **90′ 自检**：晋级故事/加时/点球 **≠** 竞彩胜平负三点。  
7. **continuation_guest**（同址七日客队刚赢再战）：默认研究星封顶 **★★★☆☆**、**不进 TOP2**；进 TOP3 须客上轮净胜≤1 **且** 主核心缺阵≥2。禁止把「主场讨债」默认焊成 TOP1。  
8. **欧战深盘客**（V17.4.33 · soft#8）：欧冠/欧联/欧协 **联赛阶段**（含揭幕）且客胜 SP≤**1.35**（或竞彩客让深度等价）→ **默认不进 TOP2**；方向层见下节硬闸（可改方向原子）。  
9. **双新军锁主**（V17.4.33 · soft#9）：双方均为该欧战/杯赛联赛阶段（或本赛季该项欧战）**首秀/新军** 且拟锁主、主胜 SP≤**1.50** → **不进 TOP2**；方向层见下节硬闸。

**噪点纪律**：单次偶然 MISS 不进清单；须同类复盘 MISS≥2 **或**结构性口径错误（如 90′）才加条。禁止把软清单升成出票弃单/改剧本方向。禁止叠「揭幕日」「心情分」等模糊条。  
**例外（亲爱的 2026-09-18）**：09-17 003/009 虽各仅 1 次，但属**可执行结构洞**（分析时看不见「观察」），升 soft#8/#9 + 方向硬闸，不靠再等第二次。

### 方向优先 · 反剧本收据（V17.4.15 · 2026-08-26 · ADHD/08-25 复盘）

**优化序**：先把胜平负方向焊对，再谈比分篮宽。比分纪律（下节）不替代本条。

写【比赛剧本】**方向**时，若使用下列叙事标签之一焊成**唯一主轴**（或据此冲 TOP1/TOP2），必须先交**【反剧本收据】**，否则方向降为 **主不败或客不败**（须选一边），研究星封顶 **★★★☆☆**，**不得进 TOP2**：

| 标签 | 典型焊法（须收据） |
|------|-------------------|
| `revenge_home` | 主场讨债 / 同址刚输要面子 |
| `weld_draw` | 势均→焊死平局三点 |
| `manage_tie` | 领先方管理比赛 / 输一场仍晋级（90′） |
| `derby_caution` | 德比/揭幕只写谨慎闷 |
| `continuation_guest` | 同址客刚赢再战却焊主胜讨债（默认降权，见 TOP 软清单#7） |

**【反剧本收据】必填字段**（可进 `01` 场次段或框架输出）：

1. `counter_direction`：最强反方向（主胜|平|客胜）  
2. `counter_one_liner`：反剧本一句话（须能对上取证槽，禁空话；**盘口异动可作为市场质疑证据写入**，如初终盘水位单向变动>30点、跨市场背离）  
3. `why_reject`：为何仍拒反剧本（伤停/战意/形态/**盘口回应**，有源）  
4. `clause_id`：授权本焊的纪律条款（如 `script#1`…`script#9` / `soft#6`）  
5. 若拒不干净（说不清反剧本为何弱，**含盘口质疑未回应**）→ **不得焊死单 1X2**：方向改 **主不败或客不败**（须选一边）。**禁止写胶着。**

赛后复盘对账：`counter_hit`（其实反剧本对了）vs `weld_ok`（主轴成立）vs `weld_failure`（条款失灵）。用条款热力图改 margin，**禁止**单次 MISS 直接加软清单行。

#### 【状态评分硬闸】（V17.4.28 · 2026-09-16 · 名气≠状态）

当 `why_reject` 以「球星名气/历史地位」为核心论据（如「C罗在」「梅西效应」「队内头牌」）时，必须追加**近 5 场评分收据**，否则 `why_reject` 视为空话，方向降为 **主不败或客不败**：

| 检查项 | 数据来源 | 硬阈值 |
|--------|---------|--------|
| 核心球员近 5 场平均评分 | Sofascore / Whoscored 球员页 | `<7.0` → 标记「状态下滑」；`≥7.5` 且 ≥2 球/助 → 标记「状态火热」 |
| 出场时间 | 同上 | 近 5 场替补出场 ≥3 场 → 标记「替补碎片，参考性降档」 |

**硬闸格式**（嵌入 `why_reject` 末尾）：
```
[状态评分硬闸] 核心球员 X：近5场均分 X.X（状态下滑/火热/正常），
进球/助攻 Y 个；[若标记状态下滑] 名气≠当前脚感，仍选强侧因 Z。
```


### 低结构平优先闸（V17.4.23 · 2026-09-07 · 周末平局复盘补丁）

**不是软清单新条，不改出票闸，不推翻 4.22.3 方向原子。** 周末复盘 28 场方向 78.6%，但「低结构 SP 贴脸」场（纽卡斯尔 2-2、赫尔城 0-0、纽约城 0-0）倾向全部焊死主胜/客胜→miss。因果硬：**结构档非只靠 margin，须兼看 SP 几何**。

**触发条件**（满足任一即 `draw_priority`，强制单子倾向写「不定」）：
1. 双方 SP 均 >2.0 且 |SP_H − SP_A| < 1.5（实力接近，庄家无明确倾向）
2. SP_D < 3.0（庄家认为平局概率 >33%，平局赔率偏低受注）
3. max(SP_H, SP_A) / min(SP_H, SP_A) < 1.8（赔率比接近，无深盘）

**强制输出**：
- 方向原子 = **主不败**（SP_H ≤ SP_A）或 **客不败**（SP_A < SP_H）
- 单子倾向 = **不定**（禁止锁主胜/客胜/锁平）
- 装箱 = 权重 Top3 混装（4.22.2），主/次/防从权重池取，**防格必须含平**
- **不得进 TOP2**；研究星封顶 ★★★☆☆

**对外句面**（`02`）：
- 旧：「主不败｜倾向主胜｜1-0 主推 / 2-1 次 / 1-1 防」
- 新：「主不败｜单子腿不定｜1-0 主推 / 1-1 次 / 2-1 防（旁挂 0-0）」
- 原则：低结构场把「平局」权重上调一档，主推不回避 1-1/0-0

脚本：`scripts/structure_gate.py`（`compute_structure_tag` / `get_enforced_direction`）· `lint_draft.py` `lint_low_structure_weld` · `lint_02_atom_text`。

### 比分推荐 · 单格 Top3（V17.4.23 · 覆盖最大化）

**不是贪婪猜最可能，是兜住最可能。** V17.4.20 纯权重 Top3 在 28 场中仅覆盖 4 场（14.3%），大量 miss 因情报层开口与权重池脱节。新版引入「三桶补偿」：情报信号 → 强制扩口/收窄/补逆转 → 再选 Top3。

**顺序硬**：双方分析/剧本 → **方向锁** → **进球档** → 写 **【情景路径】**（2–4 条，`weight`+终场叶）→ **每个比分单独计权** → **三桶补偿**（情报信号校准权重池）→ 取覆盖最大化 **Top3 单格** → 公开 **≤3**。  
**禁止**把三格当套餐。每个比分独立计权，补偿后仍独立。

| **HIGH_SCORING** | 双方近5场均总球≥2.5 / 联赛开放 / 防线残≥3 | 强制加入≥4球比分 | 2-2, 3-1, 1-3, 2-3, 3-2 |
| **LOW_SCORING** | 双方近5场均总球≤1.5 / 教练保守 / 主力前锋伤 | 强制加入≤2球比分 | 0-0, 1-0, 0-1, 1-1 |
| **REVERSAL_HOME** | 半场路径B含对方先破门且w≥0.15 | 强制加入主队逆转分 | 2-1, 3-1, 2-0 |
| **REVERSAL_AWAY** | 半场路径B含主队先破门且w≥0.15 | 强制加入客队逆转分 | 1-2, 1-3, 0-2 |

**关键纪律**：
1. 补偿分不占权重排名，只扩候选池
2. 防格优先用补偿分（确保多样性）
3. 主推/次选仍按权重，但允许补偿分挤入
4. 旁注挂屠杀/多球逃生（≥5球仍旁注）；**深盘碾压触发时**防或旁须至少一格大比分（见纪律#13）

#### 结构档与装箱

第3与第4单格权重差 **&lt;ε（默认 0.15）** → **低结构**（禁进 TOP2；`01` 仍默认交权重 Top3）。

| 结构档 | 何时 | 装箱 |
|--------|------|------|
| **低结构** | 主不败/客不败、收据拒不干净、**ε**、无焊唯一主轴 | 单子腿不定 → 主/次/防 = 权重 #1/#2/#3；倾向已定 → **先按族重排**（主/次=倾向族、防=允许集另一向）；逃生异族写 **旁注**；**不得进 TOP2** |
| **高结构** | 方向焊清、收据过闸、#3-#4 margin≥ε | 主/次 = 焊轴族单格 #1/#2；**防** = 平防 **或** 收据 ±1 球反方向；补偿分可占防格 |


**收据防格（V17.4.20 · 比分仓）**：【反剧本收据】过闸且 `counter_direction` 与焊轴**异号**时，须有一条情景叶 `weight≥τ（0.10）` 的 **±1 球**反方向分（主胜焊→**0-1**；客胜焊→**1-0**），占用公开 **防**。02 可写「真爆冷最像 0-1」。屠杀/多球反方向仍旁注。主+次不得混异族。  
**同链反回声**：情景叶与公开格全是同一胜族、无 1-1/反方向 → 视为双计，须换防格。  
**HT/FT 分轨**：`ht_path_A/B`（半场态）与 `path_A/B/C`（90′ 终场）分开写。`derby_caution` / `weld_draw` / 谨慎闷 → 必须有 **开口/对方先破门** 备路径（#8）。02 只留「上半场主/备」两句。  
**TOP2 预闸**：低结构不得进 TOP2；焊标签须 `clause_id` 绑 path 叶；同指纹 **1 次** `counter_hit` → live 禁 TOP2（不等 ≥2）。  
**禁止**：无路径任选；三格套餐。  
**旁注**：#9 屠杀/多球逃生；收据未过闸时的异族 ±1 球。收据过闸后 ±1 球进 **防**，进 `02`。  
**废止**：邻格主闸（V17.4.17）；同等合法/两簇任选（V17.4.18）；三格套餐（V17.4.19 初版）。  
**交卷口吻**：`02` 球迷话；weight / τ / margin 留 `01`。  
交卷校验：`scripts/lint_draft.py`（比分与方向允许集一致等）。


### 剧本 / 比分推荐纪律（V17.4.20 · 2026-08-27 · 球迷+分析师准确率闸）

写【比赛剧本】与【研究推荐】比分时（**改推荐质量，不做出票弃单理由；单场 MISS 不加软清单条**）：方向未过「反剧本收据」闸前，**禁止**先扩比分篮假装完成。

1. **环境维不焊方向**：天气/场地/湿度等只加权，**禁止单独焊死**胜平负方向。中游主场打争冠/榜眼客：须并列写清 **「主队先破门 → 主胜或平」** 路径，不得只留客胜主轴。  
2. **逃生口**：收据**未**过闸 → 相反 ±1 球只写 **旁注**。收据**已**过闸 → 该 ±1 球占公开 **防格**（τ≥0.10）；多球/屠杀仍旁注。开口平局研究侧可旁挂 **2-2**。  
3. **上下半场分轨**：HT 与 FT 分开写；HT 主轴与终场方向同号时必须有 **对方先破门** 备路径。比分三格对双方路径，不是几何凑邻。  
4. **进行中大比分 ≠ 终场**（08-15 米亚尔比 0-3→4-3）：上半场屠杀成立时，下半场仍须保留 **落后方追分/翻盘** 终局；禁止用半场比分锁死 90′ 方向推荐。  
5. **体能税不焊小胜上限**（08-15 威廉二世 1-4）：中周 120′/短间隔只加权；纸面明显优时 **旁注** 留大胜（如 1-4 / 0-3）。  
6. **揭幕/小球教练画像不焊平**（08-15 阿拉维斯 3-0）：揭幕战不得单独焊死平/小球；主场揭幕须并列 **主胜多球** 旁注。  
7. **领先两球 ≠ 终场锁定**（08-16 阿贾克斯 2-0→2-2、桑坦德 2-0→2-2）：研究侧可旁挂 **2-2**；公开三格按单格权重（可含 1-1 防平）。  
8. **双新帅揭幕 / 同城德比不焊「谨慎闷半场」**（08-24 富勒姆 2-3 切尔西）：须并列 **「开场见球 / 开口」**（`ht_path_B`）。开口篮旁注可挂 **2-3 / 2-2**。  
9. **须屠三球的次回合翻盘 · 旁挂多球**（08-25 林茨 4-1 凯尔特人 90′）：须净胜≥3 时 **旁注** 挂 **3-1 / 4-1**；公开 Top3 若分析把屠杀分排进前三则可进格。加时/点球≠竞彩 90′。  
10. **双方分析 → 单格 Top3**（V17.4.19+ / 4.22.2）：每个终场分单独计权；**禁止**邻格/套餐。margin&lt;ε → 低结构（仍交 #3，禁 TOP2）。  
11. **同链反回声**（V17.4.20）：伤停/形态与球迷 anecdote 不得当两条独立信号把三格全焊成同一胜族；防格须换异链路（平或收据反方向 ±1）。  
12. **continuation_guest**（V17.4.20）：同址客刚赢再战，禁止默认复仇 TOP1（见软清单#7）。  
13. **深盘碾压 · 防/旁挂屠杀格**（V17.4.26 · 2026-09-14 · 09-09 中途 + 09-11 RMA）：方向为锁主/锁客（或深让降维后的主不败/客不败且单子倾向已定强侧），**且**（让球绝对值≥2 **或** 对手近5场失球≥10 / 防线残≥3）时：公开 **防格或旁注至少一格** 须挂大比分（主屠：`3-0`/`4-0`/`5-0`/`4-1`；客屠：`0-3`/`0-4`/`0-5`/`1-4`）。禁止三格全停在 2-0/2-1/1-1 小胜带。不因此加第四公开格；不改方向仓。

### 新增：强制检查点（写进 `01`，由 lint 兜底）
