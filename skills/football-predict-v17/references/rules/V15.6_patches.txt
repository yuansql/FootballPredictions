# Patch 1 · Kryptonite（历史克星加权）
# ═══════════════════════════════════════════════════════════════════════════
# 触发：一方近 10 次正式交锋胜率 ≥ 80%（≥8胜），且该方为本场客队。
# 动作（泊松加总后、Edge 前）：
#   offset = (H2H_WinRate - 0.5) * 0.24     # 最大偏移 ±12%
#   P_A_adj = P_A_poisson * (1 + offset)
#   归一化：P_H/P_D/P_A_adj → 总和=1
# 落表：【V15.6补丁】含 Kryptonite + offset
#
# ═══════════════════════════════════════════════════════════════════════════
# Patch 2 · Zombie（垫底队受让陷阱）
# ═══════════════════════════════════════════════════════════════════════════
# 触发：主队联赛排名倒数第1或第2 且 胜场≤1 且 主队受让≥1球（竞彩 L≥+1）
# 动作：Edge_eff_Handicap = Edge_raw_Handicap * 0.60 * 0.65
#       （在 RAW_GOALS 的 0.60 之上再叠深盘士气系数 0.65）
# 强制输出：「核心投资方向」标注
#   ⚠️ 深盘陷阱预警：垫底队受让不可轻信
#
# ═══════════════════════════════════════════════════════════════════════════
# Patch 3 · Jinx（主场平局专家）
# ═══════════════════════════════════════════════════════════════════════════
# 触发：两队近 5 次在主队主场交锋，平局率 ≥ 60%（≥3平）
# 动作：
#   P_D_smoothed = P_D_poisson*0.6 + Home_Draw_Rate_Last5*0.4
#   shrink = (1 - P_D_smoothed) / (1 - P_D_poisson)
#   P_H_final = P_H_poisson * shrink
#   P_A_final = P_A_poisson * shrink
#   P_D_final = P_D_smoothed
# 若 P_D_final 为三项最高 → 最终决策平局必须首选，比分强制含 0-0/1-1
#
# ═══════════════════════════════════════════════════════════════════════════
# Patch 4 · Edge_Refine（负 Edge 强制冷门警示）
# ═══════════════════════════════════════════════════════════════════════════
# 触发：主盘口（胜平负）经所有修正后 Edge_eff ≤ -5%
# 动作：扫描 Draw / Underdog_Win
#   Edge_cold = P_model − P_fair
#   若 Edge_cold ≥ 3% → Force_Output=「冷门高赔首选：{outcome}」
#   比分强制替换为冷门典型比分（平：0-0/1-1；客冷：0-1/1-2；主冷：1-0/2-1）
# 禁止为顺应市场热门而强推负 Edge 方向。
