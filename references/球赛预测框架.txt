# 球赛预测框架 V18（情报、统一概率、真实 EV）

## 0. 执行顺序

候选分诊 → 多源取证落盘 → 情报叙事/球队画像/比赛剧本 → 方向冻结 → λ 与不确定区间 → 动态截断比分矩阵 → 各玩法概率 → 采齐在售玩法SP → 玩法路由 → 市场基准与真实 EV → 研究玩法 + 出票或空仓 → 赛前冻结 → 时间外复盘。

先研究球队，再评估价格。禁止先找高 EV 数字再补故事；也禁止把“情报优先”理解成赔率完全不能校准模型。市场去水概率是基准，实际 SP 是 EV 输入，两者角色不同。

## 1. 数据源与证据

【取证清单】至少覆盖：对阵/开赛、积分和赛程、主客或近期进失、伤停、机会质量（xG或明确代理）、H2H（若有）、实际 SP 与采集时间。

- 每项写 HIT/UNKNOWN、URL或SEARCH_Q、来源时间和摘要。没有工具或无法访问就明示，不凭记忆填精确数。
- 捷报可作为竞彩列表、基础赛况与技统主入口；俱乐部/联赛官方优先核阵容和赛程；Understat 等提供其覆盖联赛的同源 xG；其他可靠公开源可补洞。
- 单一商业站不再是所有事实的唯一权威。不同源冲突时并列写，不能挑符合剧本的一条。
- 荐单、计划单、AI推荐和“看好方向”不进证据；教练/裁判/猫页仅摘事实。
- 原始数据落 _raw，证据哈希只证明本地文件一致，不证明网页内容真实。

关键对阵、开赛时间或核心阵容未知 → 不出票。研究可继续，但标数据不足并扩大不确定区间或不给概率。

## 2. 情报、球队与剧本

【情报叙事】写伤停、轮换、赛程、战意、主客和来源。
【球队画像】分别写双方攻防、风格与对位，不以积分榜代替全部能力。
【比赛剧本】写主要路径、反剧本和方向；没有可靠一侧可观望。

排除不是必须动作。每场允许 `排除=暂缓`、`方向=观望`、`倾向=不定`。方向由情报和概率证据共同支持，不能由低赔、低结构、主客标签或历史补丁单独决定。

伤停看边际影响：角色、替补差距、对位和是否已反映在样本中。新缺不自动排边，旧缺不自动归零。没有具体机制只降低置信。

H2H 标正式/友谊、时间和阵容可比性；小样本 H2H 不直接修改概率。战意、天气、裁判和体能只作有来源的情景变量，禁止固定百分比或固定 λ 乘数。

## 3. 方向冻结与风险标记

写 EV 前记录冻排、冻向、冻侧。新证据可修订，但须写修订原因和时间；赛后不得覆盖赛前版。

【低结构平优先闸】【深盘陷阱确认书】【欧战深盘客闸】【双新军锁主闸】【杯赛揭幕闸】只提示风险。它们不能自动选择主/客不败、强制倾向不定、改变星级或禁止某种玩法。

V15.6 五补丁不再进入正式概率链。StarFactor、Kryptonite、Jinx、Zombie、Edge_Refine 若是待研究特征，须写可复用定义并进入 Shadow 验证，不得直接乘 λ、拉偏 P_H/D/A、改写比分或 EV。

跨市场比较必须统一时间点、结算规则和概率口径。竞彩三项让球与亚洲两项盘口不是同一产品，不能仅因“差一档”认定机构分歧。

## 4. λ 与统一概率

优先顺序不是“联赛级别决定分布”，而是数据质量决定能否估计：
1. 同源 xG/xGA：统一是否含点球、赛事和时间窗，做对手与主客修正。
2. 原始进失：明确 RAW_GOALS，结合对手强度、联赛基准和主客样本；不得冒充 xG。
3. 只有技统代理：标低质量，可给宽区间或不估 λ。

收缩系数、时间衰减和伤停系数由历史验证；不再固定 λ'=0.65λ+0.35LG_HALF、Edge×0.60、小样本×0.85。可用 w=n/(n+k) 表达收缩，但 k 须经 walk-forward 选择并冻结。

当前基线为动态截断独立泊松，尾部 <0.0001。所有玩法共用矩阵：胜平负、竞彩让球、总进球和精确比分不能各自调参。模型细节见 p_model手算.txt。

模型不确定度至少来自：输入误差、样本量、阵容未知、模型形式和市场分歧。不确定度落成 `λ区间=H[lo,hi]/A[lo,hi]` 并写 `区间依据=`；保守概率由区间四角点跑同一矩阵取最差值机械导出（`scripts/conservative_probability.py`），不得手工下调，也不得为过闸收窄区间。

## 5. 市场与真实 EV

p_be=1/实际SP；EV=p_model×SP-1。
市场去水概率 q_i=(1/SP_i)/Σ(1/SP)，仅作比较。

出票条件同时满足：核心数据足够、玩法概率与矩阵一致、SP有效、保守EV>0、符合预算和开售。点估计正 EV 而保守 EV 非正 → 观望。没有固定1%/3%门槛，也没有“必须降维”。

宣布“无可买/无推荐”前须采齐该场全部在售玩法的实际 SP（胜平负/让球/总进球/比分）并写采集时间；未开售写未开售。只采胜平负就下结论属于取证不足。

【玩法路由】按情报状态选研究哪条价格线：方向清+净胜清→让球/比分；方向清+净胜不清→胜平负；方向不清+总λ稳→总进球；两者都不稳→观望。路由只选价格线，不改 λ、不改矩阵、不放宽出票闸；总进球不自动更安全。

研究层与出票层分开。【研究玩法】每行带实际 SP、p_model、EV 和 `标签=非正EV|正EV`，不受保守 EV>0 限制，但不得进【今日票面】；实际出票仍按上面全部条件并落 tickets.json 审计。复式按覆盖算：命中概率=Σp_i，本金=2元×档数×倍数，EV=Σ(p_i×SP_i)/档数-1；加腿只提高覆盖率，不提高 EV。

高 EV 与市场严重背离时先排查数据、口径、阵容和模型漏项；不自动弃单，也不凭两条软叙事强行放行。复核后仍只有点估计优势 → 不出票。

## 6. 比分、总球与研究推荐

有可靠矩阵时输出概率最高的比分与总球分布，并结合情景说明；没有可靠矩阵可弃权。禁止：
- 强制总进球或比分三格；
- 强制至少一个净胜≥3；
- 因同轮小胜比例超过某值整表改稿；
- 为覆盖反方向而加入低概率“套餐”；
- 把泊松 Top1 当确定赛果。

研究星表示证据/方向可信度，投注星表示实际出票状态，两者不能互相替代。空仓仍交研究结论，但不强迫交伪精确比分。

【研究玩法】是研究层交付：只要该玩法在售且已采 SP，空仓日也应给出带价格的玩法研究行（含负 EV 行，标“非正EV”），不得因出票闸把整场研究结论压成“无推荐”。

## 7. 票面、预算与相关性

票面可空仓。稳/博只是波动偏好，不是固定星级、主客或让平标签。每腿写选项、SP、p_model、p_conservative；多档写全，按实际本金计算。

整票 EV=Σ(路径概率×路径派彩)/本金-1。保守EV≤0则不出票。不要求是本金两倍，不因返还不足把胜改为让胜。

默认跨场，避免同场相关玩法假装独立。多腿相关性须显式讨论；独立相乘只是近似。多张票共腿要合并暴露，不用“客腿最多一张”等机械限制。

## 8. 赛前冻结与复盘

冻结 lean、完整三项概率、λ 与 λ 区间、保守P、模型版本、SP时间和稿件哈希，并追加 `pred-ledger.csv`（多腿票另记 `tickets-ledger.csv`）。赛后主看 Log Loss、Brier 和校准曲线；辅以出手率、Top1/Top3、实际ROI、CLV、回撤和置信区间。用 `scripts/score_ledger.py` 出这些指标与保守P 诊断；没有账本就没有校准证据。

规则升级必须 walk-forward：只用当时可得信息，按时间滚动训练/验证；旧版与候选版在未来样本并行，时间外改善才替换。不得在同一旧账本上边调边验收，也不以30场或三次同类miss作为自动升级许可证。
