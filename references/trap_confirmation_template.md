# 深盘陷阱确认书模板（V17.4.23）

> 触发：客队 ∈ 豪门名单 且 客胜赔 SP_A ≤ 1.50

---

## 【战意衰减探测器】

### 欧战夹赛检查
- [ ] 周中有欧冠/欧联/欧协联？
- [ ] 欧战是主场还是客场？（客场更疲劳）
- [ ] 欧战对手强度（利物浦 > 马尔默）？
- [ ] 首回合已领先/已落后？（领先方可能管理比赛）

**示例**（毕尔巴鄂 vs 马竞）：
> 马竞下周中欧冠**客战利物浦**（顶级对手+客场），Simeone 可能轮换 Hjulmand/Lee Kang-in。
> 事故路径：「马竞留力欧冠 → 毕尔巴鄂主场抢开局 → 1-0/2-0 主胜」

### 轮换信号检查
- [ ] 教练赛前言论提及轮换/考察替补？
- [ ] 主力前锋/中场近3场出场时间 > 270 分钟？
- [ ] 夏窗新援多 → 阵容实验期？

**示例**（贝蒂斯 vs 皇马）：
> 安帅表示「部分主力需要休息」，Mbappé 近3场 270 分钟全勤。
> 事故路径：「皇马轮换 → 贝蒂斯高压逼抢 → Parrott 绝杀 1-0」

---

## 【客场疲劳计算器】

### 客场链检查
- [ ] 本场是连续第 N 个客场？（N≥2 风险上升）
- [ ] 上次客场距离 > 500km？（西甲东部→北部、英超南部→东北部）
- [ ] 上次客场后休息 < 72 小时？

**示例**（埃弗顿 vs 曼联）：
> 曼联上轮客场 Brighton，本轮客场埃弗顿（连续客+北方湿冷）。
> 事故路径：「连续客场体能下降 → 埃弗顿定位球破门 → 1-1/2-2 平局」

### 主队战意不对称
- [ ] 主队近3轮不胜/垫底/刚换帅？
- [ ] 主队主场有复仇/首胜/保级的强烈叙事？
- [ ] 主队近期主场 xG > 实际进球（被低估）？

**示例**（贝蒂斯 vs 皇马）：
> 贝蒂斯主场对皇马近2年不败，Sevilla  derby 氛围，球迷高压逼抢。
> 事故路径：「主场气势 + 皇马轮换 → 贝蒂斯反击 1-0」

## 【可拒绝的事故路径】总结

| 类型 | 触发 | 事故比分 | 如何拒绝 |
|------|------|---------|---------|
| 欧冠夹赛 | 周中客场打强敌 | 1-0/2-1 主胜 | 主力轮换证据 |
| 连续客场 | N≥2 + 长距离 | 1-1/2-2 平局 | 体能数据/跑动距离 |
| 主队战意 | 保级/复仇/首胜 | 1-0/2-0 主胜 | 主队近3场 xG 趋势 |
| 轮换实验 | 新援多/教练表态 | 2-1/3-1 主胜 | 首发名单预测 |

##  verdict 输出

```
风险分数：_/5
结论：clean / caution / dirty
建议：...
```

- **clean（0分）**：深盘但无疲劳信号 → 正常分析，仍须反剧本收据
- **caution（1-2分）**：有1-2个信号 → 反剧本收据 + 防格含主队胜
- **dirty（≥3分）**：方向降级为「主不败/客不败」+ 倾向不定 + 不进TOP2
