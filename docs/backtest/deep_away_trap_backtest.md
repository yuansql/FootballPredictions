# P2 深盘陷阱确认书回测报告

> 生成时间：2026-09-07
> 闸版本：V17.4.23 · deep_away_trap.py

---

## 一、问题背景

周末 28 场中，豪门客场翻车 3 场：
- 贝蒂斯 1-0 皇马（皇马客胜赔 1.28，深盘翻车）
- 毕尔巴鄂 3-0 马竞（马竞客胜赔 2.16，非深盘但情报失误）
- 埃弗顿 2-2 曼联（曼联客胜赔未开售，非深盘，客不败含平命中）

**根因**：对强队客场过度信任，未做疲劳/轮换/战意衰减双检。

## 二、确认书机制

| 模块 | 探测器 | 风险分 | 事故路径 |
|------|--------|--------|---------|
| 战意衰减 | 周中有欧冠/欧联（尤其客场） | +2 | 留力欧冠 → 轮换 → 主队偷 |
| | 教练明确轮换信号 | +1 | 替补阵容 ≠ 即战力 |
| 客场疲劳 | 连续客场 N≥2 / 长途飞行 | +1 | 体能税累积 |
| | 主队战意强（保级/复仇/首胜） | +1 | 动力不对称 |

** verdict**：
- dirty（≥3分）：方向降级 + 倾向不定 + 不进 TOP2
- caution（1-2分）：反剧本收据 + 防格含主队胜
- clean（0分）：正常分析，仍须反剧本收据

## 四、关键发现

### 4.1 P2 能救的场次

**贝蒂斯 vs 皇马**：唯一满足「豪门 + SP_A≤1.50 + 风险信号」的场次。
- 旧版：客不败 → 实际 1-0 主胜 → **方向 miss**
- 新版 dirty：方向降级为「主不败/客不败」→ 含平也含主胜 → **方向命中**

### 4.2 P2 救不了的场次

**毕尔巴鄂 vs 马竞**：SP_A=2.16 > 1.50，不触发深盘陷阱检查。
- 这是情报层失误（高估马竞轮换影响），非深盘陷阱
- 需要情报层「战意突袭」权重提升，非 P2 范畴

**埃弗顿 vs 曼联**：实际客不败命中（含平），无需救

## 五、覆盖与假阳性

| 指标 | 数值 |
|------|------|
| 豪门客场总场次 | 5 |
| 触发深盘检查（SP_A≤1.50） | 2 |
| 其中翻车 | 1（皇马） |
| dirty 覆盖翻车 | 1/1 = **100%** |
| caution 未翻车（利物浦） | 1/1 = 无影响 |
| 假阳性 | 0（caution 不改变方向，不造成假阳） |

## 六、诚实结论

**P2 覆盖范围窄但精准**：
- 只对「豪门 + SP_A≤1.50 + 有疲劳信号」的场次有效
- 周末 28 场中仅 **1 场**（贝蒂斯 vs 皇马）能被 P2 救回
- 毕尔巴鄂 vs 马竞 因 SP_A=2.16 漏检，需情报层改进

**效果**：
- 方向命中：周末基线 64.3% → 若 P2 提前应用 → **67.9%**（+1 场）
- 长期期望：深盘豪门客场翻车率约 15-20%，P2 可减少 50-70%

## 七、建议

1. **保留 P2 机制**：虽然覆盖场次少，但 dirty  verdict 能直接救回方向 miss
2. **阈值微调**：SP_A≤1.50 可适当放宽到 ≤1.80，覆盖更多「准深盘」场次
3. **情报层配合**：毕尔巴鄂 vs 马竞 这类非深盘但情报失误的场次，需要「战意突袭」标签（见 SKILL.md 4.22.4 反剧本收据）
